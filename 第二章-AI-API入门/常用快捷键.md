# 常用快捷键：第二章 AI-API 入门

> 本章的注册、申请 Key、查用量都在浏览器里完成，这些浏览器快捷键最常用。全书的汇总见[附录《常用快捷键汇总表》](../附录-速查总览/常用快捷键汇总表.md)。

## 一、浏览器（注册 / 申请 Key / 查用量）

| 快捷键 | 作用 |
|---|---|
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` | 关闭当前标签页 |
| `Ctrl + Shift + T` | 恢复刚才关闭的标签页 |
| `Ctrl + L` | 光标跳到地址栏（直接输入网址） |
| `Ctrl + F` | 在当前页面查找文字 |
| `Ctrl + 点击链接` | 在新标签页中打开链接 |

## 二、Key 的复制与备份

| 快捷键 | 作用 |
|---|---|
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴（申请到的 Key 不要手输，直接粘贴） |
| `Win + V` | 剪贴板历史（Key 只完整显示一次，粘贴前别复制别的内容） |
| `Win + Shift + S` | 区域截图（如需备份 Key，截图后存到本地私有位置，不要上传网盘或发给他人） |
