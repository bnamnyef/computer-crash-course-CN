# 常见报错检查：第二章 AI-API 入门

> 调用 AI API 与配置 Cherry Studio 时的快速排查表。详细说明见各篇正文；全部章节的汇总见[附录《常见报错速查表》](../附录-速查总览/常见报错速查表.md)。

| 报错现象 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `401 Authentication Fails` | API Key 错误或未创建 | 到平台 API 密钥页重新创建并复制，检查是否多出空格 | [DeepSeek 错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes) |
| `402 Insufficient Balance` | 余额不足 | 前往平台充值（硅基流动需先完成实名认证） | [DeepSeek 错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes) |
| `429 Too Many Requests` | 请求速率达上限 | 降低频率、错峰请求，稍后重试 | [DeepSeek 错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes) |
| 模型名报错/模型不存在 | 用了已下线的旧模型名 | 以官方「模型 & 价格」页为准：当前为 `deepseek-v4-flash` / `deepseek-v4-pro` | [DeepSeek 模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) |
| 连接失败/超时 | base_url 填错或网络问题 | 核对 base_url：DeepSeek 为 `https://api.deepseek.com`，硅基流动为 `https://api.siliconflow.cn/v1` | [AI-API 使用](./AI-API-使用.md) |
| 硅基流动无法充值/开发票 | 未完成实名认证 | 用户中心 → 实名认证，用支付宝刷脸完成 | [硅基流动快速上手](https://docs.siliconflow.cn/cn/userguide/quickstart) |
| API Key 泄露 | 误发到公开仓库/聊天 | 立即到平台吊销并重新生成 | [AI-API 使用](./AI-API-使用.md) |
