# 常用快捷键：第四章 终端与 WSL

> 本章的日常操作都在终端里完成，这些快捷键能显著提升效率（来源为 GNU Bash 与 Windows Terminal 官方文档）。全书的汇总见[附录《常用快捷键汇总表》](../附录-速查总览/常用快捷键汇总表.md)。

## 一、终端（bash / Readline）

| 快捷键 | 作用 |
|---|---|
| `Tab` | 自动补全命令或文件名（最常用） |
| `↑` / `↓` | 翻看上一条 / 下一条命令历史 |
| `Ctrl + C` | 中断当前正在运行的命令 |
| `Ctrl + L` | 清屏 |
| `Ctrl + A` / `Ctrl + E` | 光标跳到行首 / 行尾 |
| `Ctrl + U` | 删除光标前的整行 |
| `Ctrl + R` | 反向搜索历史命令 |

## 二、Windows Terminal

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Shift + T` | 新建标签页 |
| `Ctrl + Shift + W` | 关闭标签页 |
| `Ctrl + Tab` | 在标签页之间切换 |
| `Ctrl + Shift + C` / `Ctrl + Shift + V` | 复制 / 粘贴（Ctrl+C 被保留给中断） |

## 三、VS Code 集成终端

| 快捷键 | 作用 |
|---|---|
| `` Ctrl + ` `` | 打开/关闭集成终端 |
| `` Ctrl + Shift + ` `` | 新建集成终端 |
