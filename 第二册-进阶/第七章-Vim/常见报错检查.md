# 常见报错检查：第七章 Vim

> 使用 Vim 时的快速排查表。命令原理见[《Vim 入门》](./Vim-入门.md)与[《Vim 常用语法速查》](./Vim-常用语法速查.md)；全部章节的汇总见[附录《常见报错速查表》](../../附录-速查总览/常见报错速查表.md)。

| 报错信息 / 现象 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `vim: command not found` | 未安装 Vim | `sudo apt update && sudo apt install vim` 后用 `vim --version` 验证 | [Vim 官方文档](https://www.vim.org/docs.php) |
| `E325: ATTENTION`（提示发现交换文件 `.xxx.swp`） | 上次崩溃/断连留下交换文件，或同一文件已在另一窗口打开 | 确认没有其他 Vim 在编辑同一文件后删除 `.swp`；想恢复未保存内容用 `vim -r 文件名` | [崩溃恢复 usr_11](https://vimhelp.org/usr_11.txt.html#ATTENTION) |
| `E45: 'readonly' option is set` | 文件只读，或当前用户无写权限（常见于系统配置） | 退出后用 `sudo vim 文件` 打开；或执行 `:w !sudo tee %` 保存 | [E45](https://vimhelp.org/message.txt.html#E45) |
| `E37: No write since last change` | 有未保存的修改却执行 `:q` | 要保存就 `:wq`；确定不要就 `:q!` 放弃修改 | [E37](https://vimhelp.org/message.txt.html#E37) |
| `E212: Can't open file for writing` | 目标目录不存在，或没有写权限 | 核对路径拼写、确认目录存在；系统目录用 `sudo vim` 重开 | [E212](https://vimhelp.org/message.txt.html#E212) |
| 按键"打不出字"或行为奇怪 | 不在正确的模式：普通模式里想直接打字，或插入模式里按了命令键 | 先按 `Esc` 回普通模式；要输入文字先按 `i` | [Vim 入门](./Vim-入门.md) |
| 粘贴代码时缩进一层层乱掉 | Vim 的自动缩进与终端粘贴冲突 | 粘贴前 `:set paste`，粘贴后 `:set nopaste`；已乱可 `u` 撤销重来 | [:set paste](https://vimhelp.org/options.txt.html#%27paste%27) |
| 方向键打出 `A` `B` `C` `D` | 装的是精简版，或处于兼容模式 | 安装完整版 `sudo apt install vim`；或先用 `hjkl` 移动 | [Vim 官方文档](https://www.vim.org/docs.php) |
| 中文显示乱码 | 编码不是 UTF-8 或文件编码识别错误 | 临时 `:set encoding=utf-8`；打开的文件编码不对用 `:e ++enc=utf-8` 重开 | [:set encoding](https://vimhelp.org/options.txt.html#%27encoding%27) |
| 误删 / 改坏了内容 | 误操作 | 立刻 `u` 撤销、`Ctrl + r` 重做；崩溃后用 `vim -r 文件名` 恢复 | [撤销 undo](https://vimhelp.org/undo.txt.html) |
