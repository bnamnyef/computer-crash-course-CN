# 第七章导读：终端里的编辑器 Vim（选修）

> 本篇是**选修章**：建议学完前六章、已经在终端里操作自如之后再来看。Vim 是 Linux 世界里几乎"无处不在"的文本编辑器——当 VS Code 用不上、只能面对终端时，它就是你的救急工具。先混个脸熟，再动手，不需要一次学会。

## 一、为什么要学这一章？

- **服务器和 WSL 里常常只有终端**：SSH 登录一台服务器时没有图形界面，改配置只能靠 `nano`、`vim` 这类终端编辑器；
- **Vim（或它的前身 vi）几乎预装在每一台 Linux 上**：会一点 Vim，是排查服务器问题、修改配置文件时的通用技能；
- **键位逻辑值得单独学**：Vim 的操作方式与常见编辑器完全不同（比如为什么用 `hjkl` 移动光标），值得花一章建立正确认识；
- **选修，不影响主线**：前六章的内容不依赖本章，你可以现在学，也可以收藏起来等真正用到时再查。

## 二、名词铺垫（先混个脸熟，不用背）

| 名词 | 一句话解释 | 生活比喻 |
|---|---|---|
| Vim | 全称 Vi IMproved，Linux 上最经典的终端文本编辑器 | 键盘版的记事本 |
| vi | Vim 的前身，几乎所有 Linux 都自带 | Vim 的"老前辈" |
| 模式 | Vim 区分"输入文字"和"执行命令"的不同状态 | 同一个键盘的两套功能 |
| 普通模式 | 默认模式：按键是命令（移动、删除、复制） | 指挥官模式 |
| 插入模式 | 按键会直接输入文字 | 打字模式 |
| 命令行模式 | 按 `:` 进入，输入保存、退出、替换等命令 | 给 Vim 下指令 |
| 交换文件 | 编辑时生成的临时文件（`.文件名.swp`），用于崩溃恢复 | 自动存档 |
| vimtutor | Vim 自带的 30 分钟互动教程 | 官方新手关 |
| `.vimrc` | Vim 的配置文件，用来保存个人设置 | Vim 的"设置面板" |

## 四、学习建议

1. **先跑一遍 `vimtutor`**：在终端输入 `vimtutor`，跟着做完约 30 分钟，比看任何教程都有效；
2. **只记三件事就能活下来**：`Esc` 回到普通模式、`i` 进入插入模式、`:wq` 保存退出——其余全部随用随查；
3. **拿临时文件练手**：先练 `vim /tmp/练习.txt`，不要一上来就改 `~/.bashrc` 或系统配置；
4. **不必追求"纯键盘流"**：Vim 的高级技巧（宏、分屏、插件）用到再学，本教程只覆盖日常够用的一小部分。
