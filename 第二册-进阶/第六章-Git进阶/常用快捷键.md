# 常用快捷键：第六章 Git 与 VS Code

> Git 是命令行工具，没有"快捷键"，但配合 VS Code 和终端历史功能能省很多事。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——**Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`**。

## 一、VS Code 与 Git

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Ctrl + Shift + G` | 打开「源代码管理」面板（查看改动、输入提交信息） |
| 通用 | `Ctrl + Shift + P` 输入 `Git:` | 执行 Git 相关命令（如 Git: Commit、Git: Push） |
| 通用 | 代码行上悬停 | GitLens 插件：显示这行是谁、什么时候改的（blame） |

## 二、终端里操作 Git

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `↑` / `↓` | 翻看历史命令（重复执行 `git status` 等） |
| 通用 | `Ctrl + R` | 反向搜索历史命令（输入 `push` 找回上次的推送命令） |
| 通用 | `Tab` | 补全分支名、文件名 |
