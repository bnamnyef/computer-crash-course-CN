# 常见报错检查：第五章 Git

> 使用 Git 时的快速排查表。命令原理见[《Git 入门》](./Git-入门.md)与[《Git 进阶》](./Git-进阶.md)；全部章节的汇总见[附录《常见报错速查表》](../../附录-速查总览/常见报错速查表.md)。

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `git: command not found` | 未安装 Git | `sudo apt install git` 后 `git --version` 验证 | [Pro Git 1.5](https://git-scm.com/book/zh/v2/%e8%b5%b7%e6%ad%a5-%e5%ae%89%e8%a3%85-Git) |
| `fatal: not a git repository` | 不在仓库内或未 `git init` | 确认目录里有 `.git`；没有就 `git init` | [Git 入门](./Git-入门.md) |
| `Please tell me who you are` | 未配置用户名和邮箱 | `git config --global user.name "你的名字"` 与 `user.email` | [Pro Git 1.6](https://git-scm.com/book/zh/v2/%e8%b5%b7%e6%ad%a5-%e5%88%9d%e6%ac%a1%e8%bf%90%e8%a1%8c-Git-%e5%89%8d%e7%9a%84%e9%85%8d%e7%bd%ae) |
| 推送时提示密码认证被移除 | GitHub 已移除密码认证 | 改用 token（当密码输入）或 SSH 密钥 | [Git 进阶](./Git-进阶.md) |
| `fatal: remote origin already exists` | 重复添加远程仓库 | 用 `git remote set-url origin 新地址` 修改 | [Git 进阶](./Git-进阶.md) |
| 推送被拒（non-fast-forward） | 远程有新提交而本地没有 | 先 `git pull` 合并再 `git push` | [Git 进阶](./Git-进阶.md) |
| 合并冲突（`<<<<<<<` 标记） | 两边改了同一个文件 | 手动保留正确内容，删除冲突标记后 `git add` + `git commit` | [Pro Git 3.2](https://git-scm.com/book/zh/v2/Git-%e5%88%86%e6%94%af-%e5%88%86%e6%94%af%e7%9a%84%e6%96%b0%e5%bb%ba%e4%b8%8e%e5%90%88%e5%b9%b6) |
