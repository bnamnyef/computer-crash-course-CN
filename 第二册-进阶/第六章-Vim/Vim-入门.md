# Vim 入门

> 本章属于「计算机使用速成」选修第六章。学完本章，你将能在终端里打开、编辑并保存文件，不再被"只能敲命令"的场景卡住。完整命令表见[《Vim 常用语法速查》](./Vim-常用语法速查.md)。

### 本章学完你能做什么

- 确认或安装 Vim，用 `vim 文件名` 打开（或新建）文件
- 说清 Vim 的模式是怎么回事，熟练用 `Esc` 与 `i` 在普通模式和插入模式间切换
- 用 `hjkl` 等键移动光标，完成输入、删除、复制粘贴、撤销与查找替换
- 保存并退出（`:wq`），放弃修改并退出（`:q!`）
- 用官方教程 `vimtutor` 继续练习

## 一、Vim 是什么？

Vim 全称 **Vi IMproved**，是 vi 编辑器的增强版，也是 Linux 上最经典的**终端文本编辑器**：没有菜单、没有鼠标，全靠键盘操作。

- **它和 VS Code 的分工**：日常写代码用 VS Code（图形界面、鼠标友好）；到了只能敲命令的场景（SSH 登录服务器、在 WSL 里改配置、系统进不去桌面时救援），就是 Vim 的主场；
- **为什么值得会一点**：Vim（或它的前身 vi）几乎预装在每一台 Linux 上——它是"哪里都有、一定能用"的那个编辑器；
- **它最大的特点是模式编辑**：同一个键盘，在不同模式下含义完全不同。这也是新手最容易迷惑的地方，下一节专门讲。

## 二、安装与启动

大多数 Linux 发行版已经自带 `vim`，先确认一下（在 WSL 终端里执行）：

```bash
vim --version     # 看到版本号即已安装
```

如果提示 `command not found`，用 apt 安装完整版：

```bash
sudo apt update
sudo apt install vim
```

启动与退出：

```bash
vim 文件名        # 打开文件；文件不存在则新建
vimtutor          # 打开官方的互动教程（强烈推荐）
```

## 三、四种模式（先搞懂这个）

| 模式 | 怎么进入 | 干什么用 |
|---|---|---|
| 普通模式 | 打开 Vim 后的默认模式；随时按 `Esc` 回来 | 移动光标、删除、复制、撤销——所有"命令"都在这里按 |
| 插入模式 | 在普通模式按 `i` / `a` / `o` | 输入和修改文字 |
| 命令行模式 | 在普通模式按 `:` | 保存、退出、替换、设置等命令 |
| 可视模式 | 在普通模式按 `v`（按字符）或 `V`（按行） | 先选中一段文字，再执行删除、复制等操作 |

> **新手第一守则**：如果 Vim 的行为变得奇怪、按键打不出字或变成了奇怪操作，先按 `Esc` 回到普通模式，再重试。

## 四、最常用的操作

### 1. 移动光标（普通模式）

| 按键 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左 / 下 / 上 / 右移动（对应方向键，但手指不用离开主键区） |
| `w` / `b` | 跳到下一个 / 上一个单词开头 |
| `0` / `$` | 跳到行首 / 行尾 |
| `gg` / `G` | 跳到文件开头 / 文件末尾 |
| `:n` | 跳到第 n 行（如 `:20` 跳到第 20 行） |
| `/关键词` | 向下查找，按 `n` 跳到下一个匹配 |

### 2. 输入文字

在普通模式按 `i`（光标前插入）、`a`（光标后追加）或 `o`（在下一行新开一行），进入插入模式输入文字，输完按 `Esc` 回普通模式。

### 3. 删除与撤销

| 按键 | 作用 |
|---|---|
| `x` | 删除光标所在的一个字符 |
| `dd` | 删除（剪切）整行 |
| `dw` | 删除一个单词 |
| `u` | 撤销上一步操作 |
| `Ctrl + r` | 重做（撤销的撤销） |

### 4. 复制与粘贴

| 按键 | 作用 |
|---|---|
| `yy` | 复制整行 |
| `p` | 在光标后粘贴 |
| `dd` + `p` | "剪切"整行再粘贴到别处（`dd` 删掉的内容会进剪贴板） |

### 5. 查找与替换

```vim
/word              " 向下查找 word，n 下一个、N 上一个
:s/old/new/g       " 当前行：把所有 old 替换成 new
:%s/old/new/g      " 全文替换
:%s/old/new/gc     " 全文替换，每个都问你是否确认
```

### 6. 保存与退出

| 命令 | 作用 |
|---|---|
| `:w` | 保存 |
| `:q` | 退出（没有未保存修改时） |
| `:wq` 或 `ZZ` | 保存并退出（最常用） |
| `:q!` | 强制退出，丢弃所有修改 |
| `:e!` | 丢弃修改，重新加载文件 |

## 五、练习：用 vimtutor 走一遍

`vimtutor` 是 Vim 自带的官方教程，约 30 分钟，包含移动、删除、复制、查找替换等全部基础操作。在终端执行：

```bash
vimtutor
```

跟着提示逐课完成即可；中途想退出可以按 `Esc` 后输入 `:q!`。做完这一遍，本章的内容基本就都练到了。

## 小结与练习

1. 用 `vim --version` 确认 Vim 已安装，没有就用 `sudo apt install vim` 装上。
2. 运行 `vimtutor`，完整做一遍（这是本章最重要的练习）。
3. 新建一个练习文件：`vim /tmp/vim练习.txt`，输入几行文字，用 `:wq` 保存退出；再打开它，练习 `dd` 删行、`u` 撤销、`yy` `p` 复制粘贴、`/` 查找、`:%s/old/new/g` 替换。
4. 故意在有未保存修改时输入 `:q`，观察报错 `E37`，再用 `:q!` 放弃修改退出，体会两者的区别。
5. 把[《Vim 常用语法速查》](./Vim-常用语法速查.md)收藏起来，以后随用随查；遇到问题看[《常见报错检查》](./常见报错检查.md)。

## 术语中英对照

| 中文 | 英文 | 一句话说明 |
|---|---|---|
| 普通模式 | Normal mode | 默认模式，按键是命令 |
| 插入模式 | Insert mode | 按键直接输入文字 |
| 命令行模式 | Command-line mode | 按 `:` 后输入命令 |
| 可视模式 | Visual mode | 先选中文本再操作 |
| 交换文件 | Swap file | 用于崩溃恢复的临时文件 |
| 撤销 / 重做 | Undo / Redo | `u` / `Ctrl + r` |
