# Vim 常用语法速查

> 本章属于「计算机使用速成」选修第六章。这里是 Vim 日常够用的全部命令，建议收藏随查；原理讲解见[《Vim 入门》](./Vim-入门.md)，报错排查见[《常见报错检查》](./常见报错检查.md)。

## 一、模式

| 按键 | 作用 |
|---|---|
| `i` | 在光标前进入插入模式 |
| `a` | 在光标后进入插入模式（追加） |
| `o` | 在下一行新开一行并进入插入模式 |
| `Esc` | 回到普通模式（迷路时先按它） |
| `v` / `V` | 进入可视模式（按字符）/ 可视行模式（按行） |
| `:` | 进入命令行模式 |

## 二、移动

| 按键 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左 / 下 / 上 / 右移动光标 |
| `w` / `b` | 下一个 / 上一个单词开头 |
| `0` / `$` | 行首 / 行尾 |
| `gg` / `G` | 文件开头 / 文件末尾 |
| `:n` | 跳到第 n 行（如 `:20`） |
| `Ctrl + f` / `Ctrl + b` | 向下 / 向上翻页 |
| `%` | 在括号上按：跳到匹配的另一半括号 |

## 三、编辑

| 按键 | 作用 |
|---|---|
| `x` | 删除光标所在字符 |
| `dd` | 删除（剪切）整行 |
| `yy` | 复制整行 |
| `p` | 粘贴（在光标之后） |
| `u` | 撤销 |
| `Ctrl + r` | 重做 |
| `.` | 重复上一次操作 |
| `dw` | 删除一个单词 |
| `diw` | 删除一个单词（不含周围空格） |
| `ci"` | 修改双引号内的内容，改完按 `Esc` 返回 |
| `dG` | 从光标处删除到文件末尾 |
| `5dd` | 删除 5 行（数字 + 命令 = 重复执行 n 次） |

## 四、查找替换

| 命令 / 按键 | 作用 |
|---|---|
| `/word` | 向下查找 word |
| `n` / `N` | 跳到下一个 / 上一个匹配 |
| `:s/old/new/g` | 当前行替换（`g` 表示行内全部替换） |
| `:%s/old/new/g` | 全文替换 |
| `:%s/old/new/gc` | 全文替换，逐个确认（`c` = confirm） |

## 五、保存退出

| 命令 | 作用 |
|---|---|
| `:w` | 保存 |
| `:q` | 退出（无修改时；有修改会提示 `E37`） |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | 强制退出，丢弃所有修改 |
| `:e!` | 丢弃修改，重新加载文件 |

## 六、进阶

| 命令 / 按键 | 作用 |
|---|---|
| `:set nu` | 显示行号 |
| `:set paste` | 粘贴模式，避免粘贴代码时缩进自动乱掉（粘贴完可用 `:set nopaste` 关掉） |
| `>>` / `<<` | 当前行右缩进 / 左缩进 |
| `J` | 把下一行合并到当前行 |
| 数字 + 命令 | `5dd` 删 5 行、`3j` 向下移 3 行等，数字表示重复次数 |

> 高效编辑小组合：`.` 重复上一次操作，`u` 撤销，二者配合可以"改一次、用多次、错了就撤"。
