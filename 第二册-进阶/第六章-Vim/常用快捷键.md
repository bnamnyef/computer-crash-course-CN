# 常用快捷键：第六章 Vim

> Vim 是纯键盘编辑器——它的"快捷键"就是全部操作命令，完整版见[《Vim 常用语法速查》](./Vim-常用语法速查.md)。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。

## 一、模式切换（最高频）

| 快捷键 | 作用 |
|---|---|
| `Esc` | 回到普通模式（迷路时先按它） |
| `i` / `a` / `o` | 进入插入模式：光标前 / 光标后 / 下一行 |
| `:` | 进入命令行模式 |
| `v` / `V` | 可视模式 / 可视行模式 |

## 二、普通模式：移动与编辑

| 快捷键 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左 / 下 / 上 / 右移动光标 |
| `gg` / `G` | 跳到文件开头 / 末尾 |
| `0` / `$` | 行首 / 行尾 |
| `/word` / `n` | 向下查找 / 下一个匹配 |
| `x` / `dd` | 删除字符 / 删除整行 |
| `yy` / `p` | 复制整行 / 粘贴 |
| `u` / `Ctrl + r` | 撤销 / 重做 |
| `.` | 重复上一次操作 |
| `dw` / `ci"` | 删除一个单词 / 修改引号内的内容 |

## 三、命令行模式：保存与设置

| 命令 | 作用 |
|---|---|
| `:w` / `:q` | 保存 / 退出 |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | 强制退出，丢弃修改 |
| `:set nu` | 显示行号 |
| `:set paste` | 粘贴模式（防止粘贴时缩进乱掉） |
| `:%s/old/new/g` | 全文替换 |

> 想在 VS Code 里练习同样的键位？可以安装 [Vim 插件](https://marketplace.visualstudio.com/items?itemName=vscodevim.vim)（可选）。
