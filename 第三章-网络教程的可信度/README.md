# 第三章导读：先学会分辨，再开始自学

> 前两章帮你装好了工具、学会了用 AI，但从这一章开始，你要面对真正的自学：**网上教程那么多，哪些能信？** 本章教你一套可执行的分辨方法，为第四章（全书最难的 WSL 环境搭建）提前备好"避坑手册"。

## 一、为什么要学这一章？

- 你以后遇到的每一个新软件、新报错，几乎都靠教程和官方文档解决——分不清好坏，就会"复制粘贴就报错"；
- 第四章是全书报错最多的一章（WSL、conda 配置），本章的"三关验证 + 排查流程"正好在第四章实战；
- 2026 年的自学已经离不开 AI 生成的答案，学会交叉验证 AI 内容，是新的必备技能。

## 二、名词铺垫（先混个脸熟，不用背）

| 名词 | 一句话解释 | 生活比喻 |
|---|---|---|
| 教程（Tutorial） | 官方或社区提供的上手引导，步骤可照做 | 菜谱 |
| 手册（Manual） | 官方对功能的权威说明，最准确 | 说明书 |
| 官方文档 | 软件开发者/维护团队发布的文档 | 官方说明书 |
| 社区 | 用户自发分享经验的内容平台（知乎、Stack Overflow 等） | 邻居们的经验分享 |
| 过时 | 内容与当前软件版本不匹配、不再适用 | 旧版地图 |
| 报错信息 | 程序出错时的提示文字，可直接当搜索关键词 | 故障代码 |
| 幻觉 | AI 生成看似合理但并非事实的内容 | 一本正经地胡说 |

## 四、学习建议

1. **方法比结论重要**：本章教的不是"哪个网站好"，而是一套可以迁移的检查流程——之后遇到任何教程都用它。
2. **带着第四章的问题学**：如果愿意，可以先瞄一眼第四章的 WSL 安装，然后带着"如何判断这篇教程"的问题回来学本章。
3. **练习不要跳过**：甄别实战篇的 4 个案例请亲自走一遍三关，动手一次胜过读十遍。
