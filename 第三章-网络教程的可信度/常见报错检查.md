# 常见报错检查：第三章 网络教程的可信度

> 本章不涉及软件安装，最常见的"报错"是**照着教程做却报错**。下面是把三关验证变成的排查清单；详细案例见[《甄别实战》](./甄别实战-判断一个教程.md)，全部章节汇总见[附录《常见报错速查表》](../附录-速查总览/常见报错速查表.md)。

## 照着教程做却报错？逐项检查

| 检查项 | 问自己 | 处理 |
|---|---|---|
| 版本匹配 | 教程发布时间？针对的软件版本与我一致吗？ | 对照官方文档的当前写法；模型名、包名、命令参数以官方页为准 |
| 命令安全 | 每条命令我是否都看得懂？含 `sudo`、`curl \| bash`、`rm` 吗？ | 先弄懂命令作用再执行，不理解就不执行 |
| 结果验证 | 教程说成功就算成功？ | 用验证命令自查（如 `conda config --show channels`），以结果为准 |
| 来源核实 | 教程/解法来自哪？域名是官方吗？ | 官方优先；社区内容多篇对照取交集，CSDN 仅兜底 |

## 其他常见问题

| 报错现象 | 常见原因 | 排查与解决 |
|---|---|---|
| 教程里的命令报"找不到" | 教程过时或软件未装 | 先核对版本，再查对应章节的「常见报错检查」 |
| 页面打不开 / 下载很慢 | 网络问题，或域名并非官方 | 检查网络与代理；核实域名后换官方镜像 |
| 复制粘贴后结果和教程不一样 | 缺少前置步骤或版本不同 | 回到教程开头按顺序重来，对照官方文档 |
