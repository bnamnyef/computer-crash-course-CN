# 计算机使用速成教程

本项目是一份面向**零基础初学者**的电脑使用速成教程，帮助你建立对 Windows 系统、开发环境（WSL）、Python、AI 工具与终端编辑器的基本认识。所有章节均基于官方文档撰写，每篇文末附「参考官方文档」链接，供你进一步查阅。

## 本教程适合谁

- 刚接触电脑、想系统了解 Windows 与文件管理的初学者
- 想在自己的电脑上搭好 Linux（WSL）+ Python + AI 编程工具链的人
- 想学会辨别网络教程好坏、不再"复制粘贴就报错"的人

## 如何使用本教程

1. **按顺序学习**：全书分两册——**第一册为基础**（第一~四章：Windows → AI-API → 教程甄别 → WSL 开发环境），**第二册为进阶**（第五章 Git、选修第六章 Vim）。第一~四章有依赖关系，建议按序学习；第六章 Vim 是选修，不影响主线，可等用到时再学。附录随时查阅。
2. **动手实践**：教程中的命令和操作请亲自在电脑上执行。只看不练，学完就忘；环境类配置（WSL、conda）尤其需要实操。
3. **善用官方文档**：每篇文档末尾的「参考官方文档」是内容的权威来源，遇到疑问先去查官方文档，比搜博客更可靠。
4. **随时回看**：本教程的目录结构就是知识地图，忘了某个操作（如如何添加环境变量、如何激活 conda 环境），直接回到对应章节查找；报错先查所在章节的「常见报错检查」，或在附录速查总览里按章节定位。

## 项目结构与命名约定

本教程的目录就是知识地图，也方便你按名字快速找到内容：

- **分册目录**：`第X册-主题`（如 `第一册-基础`、`第二册-进阶`）；
- **章节文件夹**：位于册目录下，`第X章-主题`（如 `第一册-基础/第一章-Windows入门`），附录为根目录的 `附录-速查总览`；
- **文件名**：不使用空格，主题与子主题之间用连字符连接（如 `软件安装-VSCode.md`、`甄别实战-判断一个教程.md`），链接直接引用文件名，无需 `%20` 转义；
- **章内 `README.md`**：该章导读（名词铺垫 + 路线图），是每章的第一篇；
- **速查表统一命名**：每章都有 `常见报错检查.md` 与 `常用快捷键.md`，附录《常见报错速查表》《常用快捷键汇总表》按章节汇总——**章内速查表与附录汇总是有意设计的两级结构，修改条目时两处需同步**；
- **格式约定**：正文篇均含「本章学完你能做什么」「小结与练习」「参考官方文档」；速查类文件用表格 + 官方链接。

> 想为教程补充内容时，请遵循上述命名与格式，并同步更新本 README 目录。

## 学习建议

- **环境配置类步骤（如 WSL、conda）出错时**：绝大多数是版本或路径问题，对照官方文档的步骤逐一检查，别急着换教程。
- **动手顺序参考**：装好 VS Code 后，边读第一章边用它写 Markdown 笔记；第四章装好 WSL 与 mamba/conda 后，日常小练习直接在 base 环境里做即可，**不必为每个练习新建环境**。但请记住两点：一是 **base 环境务必保持干净**——它是最常用、最稳定的默认环境，不要随意塞满依赖包；二是当某个项目需要不同的 Python 版本或一套特定依赖时，**新建独立环境是必要的**（`mamba create -n 项目名 python=3.11`），让依赖互相隔离、互不污染。
- **遇到报错先看所在章节的「常见报错检查」**：每章都有对应排查表，附录《常见报错速查表》按章节汇总全部条目，附官方排障链接；查不到再按第三章的方法去官方文档排查。
- **学完一章，回头补一章**：不需要一次读完，按需查阅即可——本 README 就是你的索引。

祝学习愉快，早日从"用电脑"进阶到"会配环境、会自学、会用版本控制、会改终端里的配置"。
