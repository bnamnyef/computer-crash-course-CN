# 如何购买靠谱 Token：三类渠道与避坑清单（零基础入门）

### 本章学完你能做什么

- 分清「模型提供商」「聚合平台（模型供应商）」「中转站」三类渠道，知道各自的本质与可信度；
- 说出 DeepSeek、OpenAI 等官方平台的特点与优势；
- 说出 OpenRouter、硅基流动等正规聚合平台的特点与优势；
- 识别中转站的典型特征与风险，理解"低价"背后的代价；
- 掌握购买 Token 的推荐顺序与"四查"检查清单，从此只花靠谱的钱。

## 一、先搞清楚：你买的是什么？

上一节说过，Token 是模型计费的基本单位——**买 Token，就是买调用大模型 API 的额度**。但同一个模型，不同渠道买到的"服务"完全不同。市面上主要有三类渠道：

| 渠道 | 本质 | 可信度 | 典型例子 |
| --- | --- | --- | --- |
| 模型提供商 | 训练并发布模型的厂商自己的官方平台 | 最高 | DeepSeek、OpenAI、Google、Anthropic |
| 聚合平台（模型供应商） | 正规企业批量采购多家官方 API，合规转售 | 高 | OpenRouter、硅基流动 |
| 中转站 | 未经官方授权的个人/小团队转售或逆向转接 | 低 | 电商平台、QQ 群里卖的"低价 API" |

## 二、模型提供商：官方渠道最可靠

**模型提供商就是"造模型的厂商自己开的店"**——DeepSeek 的 platform.deepseek.com、OpenAI 的 platform.openai.com、Google 的 AI Studio（aistudio.google.com）、Anthropic 的 console.anthropic.com，都是它们的官方售卖渠道。

官方平台的优势：

1. **模型最强、最新**：新模型第一时间在官方开放，不会出现"官网有了、渠道没有"的情况；
2. **数据只流向官方**：你的提问直接发给厂商，不经任何中间人，隐私最有保障；
3. **计费透明**：官方定价明码标价，按 token 实扣，不存在"偷偷多扣"；
4. **有官方文档与支持**：API 文档、错误码、帮助中心齐全，出问题能查到权威解答；
5. **服务稳定**：官方维护，不会突然跑路。

需要注意：OpenAI、Anthropic、Google 等海外平台对国内访问有限制，**国内用户优先选择 DeepSeek 等国内厂商的官方平台**（具体注册与充值方法见 [AI-API 使用](./AI-API-使用.md) 一文）。

## 三、聚合平台：正规的"模型超市"

聚合平台（也叫模型供应商、模型聚合平台）是**正规企业**批量采购多家厂商的官方 API 后，统一对外提供服务——相当于"模型超市"：一个账户、一把 Key，就能对比和使用多家模型。常见的有海外平台 OpenRouter 和国内平台硅基流动。

### 1. OpenRouter（openrouter.ai）

- 官网自称"统一接口"：一个 Key 即可调用 **500+ 个模型、80+ 家提供商**（含 OpenAI、Anthropic、Google 等全系列）；
- **按量充值、统一账单**：充值 Credits 后所有模型共用一个余额，官方 FAQ 说明其**不赚模型差价**（不加价转售），只在充值时收取少量手续费；
- **自动故障转移**：某家提供商挂了会自动切换备选，稳定性更好；
- 完全兼容 OpenAI 接口格式，现有代码改个 `base_url` 就能用；
- 缺点：面向海外用户。

### 2. 硅基流动（SiliconFlow，cloud.siliconflow.cn）

- 国内正规平台，支持短信/邮箱注册，需**实名认证**（见 [AI-API 使用](./AI-API-使用.md)）；
- **模型广场**提供大量开源模型（Qwen 系列等），并有多款**免费模型**，适合零成本入门试玩；
- 支持支付宝等国内支付方式，可开发票；
- 接口兼容 OpenAI 格式。

聚合平台的优势：

1. **一个 Key 试遍多家模型**，方便对比哪家适合你；
2. 有免费模型/免费额度，入门成本低；
3. 统一账单、统一管理，不用在每个厂商各注册一遍；
4. 正规企业运营，有资质、有客服，不会"跑路"。

> 注意区分：正规聚合平台与中转站有本质区别——前者是**持牌正规企业、走官方授权采购**；后者是无授权的灰色转售。下文详述。

## 四、中转站：低价背后的高风险（不推荐）

**中转站是未经官方授权的第三方服务**，它把官方 API 包装转卖，或者逆向破解网页接口"转接"给你用。常见形态：电商平台上几块钱的"低价 API"、QQ 群/论坛里的"无限量套餐"、套壳官方网页的"免费 AI 网站"。

### 为什么它能卖得比官方便宜？

根据媒体调查与监管提示，低价来自这些灰色操作：

1. **批量注册账号薅免费额度**：用脚本注册大量官方账号，把免费额度打包转卖（官方封号就服务中断）；
2. **共享账号池**：把一个月几百美元的付费账号拆分成几十个套餐卖给多人；
3. **逆向破解网页接口**：伪造请求模拟网页版调用，官方改版即失效；
4. **小模型冒充大模型（降智）**：后台悄悄把请求路由到更便宜的模型，你付的是旗舰价，用的是入门级；
5. **虚报 Token**：计费系统是中转站自己写的，实际消耗 1000 Token 可能扣你 1500。

### 风险清单

| 风险 | 说明 |
| --- | --- |
| 封号跑路 | 上游账号被封 → 服务中断、余额打水漂；大量用户已因此吃亏，商家失联、售后群解散 |
| 模型降智 | 高峰期被偷偷降级到廉价模型，同一"产品名"底层却是不同模型 |
| 数据裸奔 | 你的提问、代码、商业文件全部经过中转站服务器，明文可被留存、分析甚至倒卖 |
| 恶意攻击 | 安全团队实测多款中转站存在恶意代码注入、窃取云凭证、盗取加密资产等行为 |
| 法律风险 | 无证经营、协助规避访问限制，平台随时可能被关停，用户难以维权 |

### 识别信号（看到就跑）

- 价格低于官方 30% 以上、"1 元几十万 Token"、永久无限量套餐（数学上不可持续）；
- 无需注册/实名，个人收款码、电商平台售卖；
- 没有企业资质、没有官网备案、没有官方文档；
- 让你改 `base_url` 指向一个陌生域名。

## 五、靠谱购买清单（推荐顺序）

1. **首选官方平台**：你常用哪家模型，就去哪家官网充值——DeepSeek 上 platform.deepseek.com，OpenAI 上 platform.openai.com；
2. **需要多模型对比、或想零成本入门**：选正规聚合平台——国内用硅基流动（支付宝方便），海外用 OpenRouter；
3. **坚决避开**：任何"比官方便宜很多"的中转站、代购、共享账号。

**下单前"四查"：**

- 查域名：是不是官网（如 platform.deepseek.com），警惕高仿站；
- 查资质：正规平台有企业主体与备案信息（网页底部可查）；
- 查价格：与官方价目表对比，明显偏低就要警惕；
- 查支付：正规对公/官方支付渠道，个人收款码一律拒绝。

**安全习惯：** 小额充值、勤查余额；API Key 绝不外传，怀疑泄露立即到平台吊销重发（详见 [AI-API 使用](./AI-API-使用.md) 的 Key 安全部分）。
