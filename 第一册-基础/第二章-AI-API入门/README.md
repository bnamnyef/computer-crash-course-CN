# 第二章导读：先认识 AI 名词，再开始调用

> 本章教你从"在网页里问 AI"升级到"用程序调用 AI"：注册平台、申请 API Key、看懂用量与费用，再装一个图形界面的 AI 客户端。全程只需要浏览器和复制粘贴。

## 一、为什么要学这一章？

- 会用 AI 是当下最实用的电脑技能，而 **API 调用**让 AI 从"聊天工具"变成"可编程能力"——批量翻译、自动写文档都能做；
- 本教程第五章要装的 AI 编程助手 OpenCode，本质也是用 API 调用大模型——先学会申请 Key，后面直接用；
- 提示词工程是"让 AI 好好干活"的方法论，现在学会，终身受益。

## 二、名词铺垫（先混个脸熟，不用背）

| 名词 | 一句话解释 | 生活比喻 |
|---|---|---|
| API | 程序之间互相调用的接口 | 餐厅的"点菜窗口" |
| API Key | 调用 AI 服务的身份凭证（一串密钥） | 会员卡密码 |
| 大模型（LLM） | 能理解并生成自然语言的 AI 模型 | 超级"翻译官" |
| Token | 模型计费与用量的基本单位 | 字数"计费单位" |
| 提示词 | 你发给模型的指令 | 给翻译官的"要求清单" |
| 模型名 | 调用时指定用哪个模型的名字 | 点名找哪位"翻译官" |
| 实名认证 | 平台按法规验证你的真实身份 | 办卡要验身份证 |
| 模型提供商 | 训练并发布模型的厂商官方平台（DeepSeek、OpenAI 等） | 造车的"车厂" |
| 聚合平台 | 正规企业统一售卖多家模型 API（OpenRouter、硅基流动） | "模型超市" |
| 中转站 | 未经官方授权的低价转售/转接服务 | 来路不明的"拼车" |

## 四、学习建议

1. **Key 是密码**：申请后妥善保管，绝不发到聊天、代码或公开仓库；泄露立即吊销重发。
2. **先读费用再看价格**：动手调用前先看"费用与用量查看"一节，国内平台先小额充值。
3. **不写代码也能用**：本教程的 Python 示例只是展示原理，用 Cherry Studio 填同一把 Key 即可开始使用。
