# 常用快捷键：第二章 AI-API 入门

> 本章的注册、申请 Key、查用量都在浏览器里完成，这些浏览器快捷键最常用。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——**Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`**。

## 一、浏览器（注册 / 申请 Key / 查用量）

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Ctrl + T` | 新建标签页 |
| 通用 | `Ctrl + W` | 关闭当前标签页 |
| 通用 | `Ctrl + Shift + T` | 恢复刚才关闭的标签页 |
| 通用 | `Ctrl + L` | 光标跳到地址栏（直接输入网址） |
| 通用 | `Ctrl + F` | 在当前页面查找文字 |
| 通用 | `Ctrl + 点击链接` | 在新标签页中打开链接 |

## 二、Key 的复制与备份

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴（申请到的 Key 不要手输，直接粘贴） |
| Windows | `Win + V` | 剪贴板历史（Key 只完整显示一次，粘贴前别复制别的内容） |
| Windows | `Win + Shift + S` | 区域截图（如需备份 Key，截图后存到本地私有位置，不要上传网盘或发给他人） |
| macOS | `Cmd + Shift + 3` / `4` / `5` | 全屏截图 / 区域截图 / 截图工具条（备份 Key 时同样注意保存在本地私有位置） |
