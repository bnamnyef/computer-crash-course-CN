# 常见报错检查：第五章 OpenCode 编程代理

> 遇到报错先看这张表，再对照[正文](./在WSL内安装OpenCode.md)。全部章节的汇总见[附录《常见报错速查表》](../../附录-速查总览/常见报错速查表.md)。

## 一、安装与启动类

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `opencode: command not found` | 未安装，或 PATH 不含安装目录 | 重新运行官方安装脚本，重启终端后验证 `opencode --version` | [OpenCode 安装](https://opencode.ai/docs/) |
| 安装脚本下载失败 / 卡住 | 网络不通或代理设置问题 | 检查网络与代理后重跑 `curl -fsSL https://opencode.ai/install \| bash`；Node.js 用户可改用 `npm install -g opencode-ai` | [OpenCode 安装](https://opencode.ai/docs/) |
| 启动后界面乱码 / 显示异常 | 终端不支持 TUI 所需字符集 | 换用 Windows Terminal 或升级终端；确认 WSL 终端编码为 UTF-8 | [Windows/WSL 说明](https://opencode.ai/docs/windows-wsl) |

## 二、模型与密钥类

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `/connect` 后模型不可用 | API Key 未配置或提供商选择错误 | 重新 `/connect` 选择正确提供商并粘贴 Key | [在 WSL 内安装 OpenCode](./在WSL内安装OpenCode.md) |
| `401 Authentication Fails` | API Key 错误、失效或未生效 | 到平台重新创建 Key，再用 `/connect` 重新配置 | [AI-API 使用](../第二章-AI-API入门/AI-API-使用.md) |
| 提示模型不存在 / 模型列表中找不到目标模型 | 模型名与提供商不匹配，或模型已下线 | 用 `/models` 重新选择；以官方「Models」页当前列表为准 | [Models](https://opencode.ai/docs/models/) |
| `/models` 里看不到已连接的提供商 | 配置未生效或配置文件写错 | 重启 OpenCode；检查项目根目录 `opencode.json` 的 `provider` 配置 | [Config](https://opencode.ai/docs/config/) |

## 三、使用类

| 报错信息 / 现象 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| 按键无反应或与终端冲突 | 终端占用了该按键（如 `Ctrl + C` 在终端是中断） | 使用 Leader 键组合（默认 `Ctrl + X`），或在 `tui.json` 中自定义 keybinds | [Keybinds](https://opencode.ai/docs/keybinds/) |
| `/init` 没有生成 `AGENTS.md` | 不在项目根目录，或当前目录无写权限 | 切到项目根目录重新启动 OpenCode，确认目录可写后再执行 `/init` | [Rules](https://opencode.ai/docs/rules/) |
| 回复中断 / 提示上下文不够 | 上下文窗口被工具输出和大量文件占满 | 开新会话；减少不必要的 MCP 工具与文件上下文 | [Agents](https://opencode.ai/docs/agents/) |
| 改动不满意想恢复 | 已让 OpenCode 修改了文件 | 在会话中撤销，必要时用 Git 回退（见第六章 Git） | [在 WSL 内安装 OpenCode](./在WSL内安装OpenCode.md) |
