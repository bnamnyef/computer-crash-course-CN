# 常用快捷键：第三章 阅读与搜索

> 本章的核心操作是"搜索和阅读教程"，这些快捷键帮你快速定位信息。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。

| 快捷键 | 作用 | 适用场景 |
|---|---|---|
| `Ctrl + F` | 在当前页面内查找文字 | 在官方文档页里定位关键词、在报错页面找关键行 |
| `Ctrl + L` | 光标跳到地址栏 | 输入 `site:learn.microsoft.com wsl` 这类限定搜索 |
| `Ctrl + T` | 新建标签页 | 边读教程边开官方文档对照 |
| `Ctrl + W` | 关闭标签页 | 清理打开的页面 |
| `Ctrl + Shift + T` | 恢复刚关闭的标签页 | 手滑关掉答案页时 |
| `Ctrl + 点击链接` | 新标签页打开链接 | 教程里的链接不离开当前页打开 |
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴 | 复制完整报错信息去搜索 |
| `Win + Shift + S` | 区域截图 | 截图报错页面发给别人或存档 |
