# 常用快捷键：第三章 网络教程的可信度

> 本章的核心操作是"搜索和阅读教程"，这些快捷键帮你快速定位信息。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——**Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`**。

| 平台 | 快捷键 | 作用 | 适用场景 |
|---|---|---|---|
| 通用 | `Ctrl + F` | 在当前页面内查找文字 | 在官方文档页里定位关键词、在报错页面找关键行 |
| 通用 | `Ctrl + L` | 光标跳到地址栏 | 输入 `site:learn.microsoft.com wsl` 这类限定搜索 |
| 通用 | `Ctrl + T` | 新建标签页 | 边读教程边开官方文档对照 |
| 通用 | `Ctrl + W` | 关闭标签页 | 清理打开的页面 |
| 通用 | `Ctrl + Shift + T` | 恢复刚关闭的标签页 | 手滑关掉答案页时 |
| 通用 | `Ctrl + 点击链接` | 新标签页打开链接 | 教程里的链接不离开当前页打开 |
| 通用 | `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴 | 复制完整报错信息去搜索 |
| Windows | `Win + Shift + S` | 区域截图 | 截图报错页面发给别人或存档 |
| macOS | `Cmd + Shift + 3` / `4` / `5` | 全屏截图 / 区域截图 / 截图工具条 | 截图报错页面发给别人或存档 |
