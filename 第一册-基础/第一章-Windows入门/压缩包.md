## 一、什么是压缩包

压缩包（也叫压缩文件、归档文件）就是**把一个或多个文件通过压缩算法打包成的一个新文件**。微软官方文档对它的定义是：压缩文件可"减小文件大小并捆绑多个文件，以便更轻松地共享"。

打个比方：桌面上散落着 10 份资料，直接发送很麻烦；把它们塞进一个行李箱再拉紧绑带，就是一个压缩包——**体积变小了，而且所有东西都装在一个箱子里**。

压缩分为两种：

- **无损压缩**：压缩后解压出来，内容与原来**一模一样**，一个字节都不差。压缩包属于这一类，所以可以放心用。
- **有损压缩**：为了体积牺牲部分数据（如 JPEG 图片、MP3 音乐）。人眼/耳朵基本分辨不出差别，但数据确实丢了。

常见压缩包后缀有 `.zip`、`.rar`、`.7z`、`.tar.gz` 等，双击它，里面往往还是"文件夹 + 一堆文件"的结构，只是它们被装进了一个外壳里。

## 二、压缩包的优势

1. **节省存储空间**：压缩后文件占用的空间更小，一个 50 MB 的文件夹压缩后可能只有 20 MB。
2. **传输更快**：体积小了，拷贝到 U 盘、发送邮件、上传网盘都更快（微软官方明确指出压缩文件"可以比未压缩的文件更快地传输到其他计算机"）。
3. **把一堆文件捆成一个**：多个文件、多个文件夹（含层级结构）打包成一个文件，分享时只发一个文件，不会漏、不会乱。
4. **可加密保护**：可以给压缩包设置密码，不知道密码打不开（此功能需要第三方软件，见下文）。

> 注意：有些文件**本身已经是压缩过的**（JPEG 图片、MP3 音乐、视频等），把它们再压进压缩包，体积几乎不会变小。压缩对文本、文档、代码这类"可压缩"的数据效果最明显。

## 三、常见压缩格式

| 格式 | 谁在用 / 出自哪 | 特点 |
| --- | --- | --- |
| `.zip` | 最通用，几乎所有系统都自带支持 | 兼容性最好，日常首选 |
| `.rar` | WinRAR 软件的专有格式 | 支持分卷压缩等高级功能 |
| `.7z` | 开源软件 7-Zip 的格式 | 压缩率通常更高 |
| `.tar` / `.tar.gz` | Linux 世界常用 | "打包 + 压缩"的组合，装软件、源码发布常见 |

日常收发文件、打包作业，用 `.zip` 就够了；收到 `.rar`、`.7z`、`.tar.gz` 也无需担心，Windows 11 或免费软件都能打开（见下节）。

## 四、如何使用压缩包

### 方法一：Windows 自带功能（最简单，先掌握这个）

**创建 ZIP 压缩包：**

1. 选中要打包的文件或文件夹（按住 Ctrl 可多选）；
2. 右键 → **发送到** → **压缩(zipped)文件夹**；
3. 在当前目录下就会生成一个同名 `.zip` 文件，可右键重命名。

> 从 Windows 11 22H2 起，Windows 已原生支持打开 `.rar`、`.7z`、`.tar`、`.tar.gz` 等多种格式；24H2 及更新版本还支持右键 →「压缩到」直接创建 7z、TAR 等格式（自带一个压缩向导，可选格式和压缩级别）。

**提取（解压）压缩包：**

1. 右键压缩包 → **全部提取**；
2. 选择解压到的位置，点「提取」；
3. 也可以直接**双击**压缩包，像普通文件夹一样浏览，再把里面的文件拖出来。

### 方法二：命令行 tar（进阶，可先跳过）

Windows 自带了 `tar` 命令（微软基于开源项目 libarchive 集成），无需安装额外软件即可在命令行打包、解包：

```cmd
tar -caf archive.zip my-folder     :: 把 my-folder 打包成 archive.zip
tar -xf archive.zip                :: 解包 archive.zip 到当前目录
```

### 限制与应对

- Windows 原生功能**不支持加密压缩包**：遇到带密码的压缩包，双击会报错打不开；想创建加密压缩包也不行。微软官方的建议是：此类需求请使用 7-Zip 或 WinRAR 等第三方软件。

### macOS 用户：访达压缩与解压

macOS 自带压缩/解压功能，日常使用零安装（官方手册：[在 Mac 上压缩和解压缩文件和文件夹](https://support.apple.com/zh-cn/guide/mac-help/mchlp2528/mac)）：

- **压缩**：在访达中选中一个或多个文件/文件夹 → 右键（或按住 Control 点按）→「压缩」。压缩单个项目生成「原名.zip」；一次压缩多个项目生成「归档.zip」；
- **解压**：双击 `.zip` 文件即可，解压结果出现在同一文件夹中；
- **命令行的 `tar`、`zip` 命令**：macOS 同样自带，用法与 Linux 一致；
- 需要打开 `.rar`、`.7z` 等格式或创建加密压缩包时，可用 Homebrew 安装第三方工具：
  ```bash
  brew install --cask keka      # 图形界面压缩工具 Keka，支持 rar/7z/加密
  brew install p7zip            # 命令行版 7-Zip
  ```
  （Homebrew 的安装与用法见[第四章《终端与 Homebrew》](../第四章-WSL与开发环境搭建/终端与Homebrew-macOS.md)。）

## 五、有哪些压缩软件

| 软件 | 是否免费 | 特点 | 官网 |
| --- | --- | --- | --- |
| Windows 自带 | 免费（系统内置） | 基础 zip 够用，零安装 | 无需下载 |
| macOS 访达自带 | 免费（系统内置） | 基础 zip 够用，零安装 | 无需下载 |
| 7-Zip | 开源免费 | 支持格式多、压缩率高，无广告 | [7-zip.org](https://www.7-zip.org/) |
| WinRAR | 共享软件（可长期试用） | 老牌软件，rar 格式的创造者 | [win-rar.com](https://www.win-rar.com/) |
| Bandizip | 免费版（含广告）/ 付费版 | 界面友好、解压速度快 | [bandisoft.com](https://www.bandisoft.com/bandizip/) |
| Keka（macOS） | 免费（官网下载；App Store 版为付费支持作者） | macOS 常用压缩工具，支持 rar/7z/加密 | [keka.io](https://www.keka.io/) |

**建议**：新手先用系统自带功能即可（Windows 用资源管理器、macOS 用访达）；当你需要**加密压缩包、解压特殊格式或追求更高压缩率**时，Windows 装一个 7-Zip、macOS 装一个 Keka 就够用了。下载请认准官网，避免从下载站拿到捆绑广告软件的安装包。

## 六、使用安全提醒

1. **别乱解压来路不明的文件**：压缩包里可以藏可执行程序（.exe 等），从网上下载的压缩包，解压前确认来源可信。
2. **加密密码忘了就找不回**：压缩包加密没有"找回密码"服务，忘记密码等于文件永久打不开，重要文件别只存加密版。
3. **别做无用功**：对 JPEG/MP3/视频等已压缩文件再压缩，体积基本不变，别指望它"瘦身"。

## 小结与练习

**练习 1（动手）**：新建一个文件夹，放几个文档/图片，用系统自带功能创建压缩包（Windows：右键 → 发送到 → 压缩(zipped)文件夹；macOS：右键 →「压缩」），对比压缩包和原文件夹的大小。

**练习 2（动手）**：把刚生成的压缩包解压到另一个文件夹（Windows：「全部提取」；macOS：双击 `.zip`），核对内容是否与原来完全一致（验证无损）。

**练习 3（动手）**：双击打开压缩包，试着从里面单独拖出一个文件到桌面（验证"当文件夹用"）。

**练习 4（自查）**：Windows 自带功能不支持什么类型的压缩包？这种情况该用什么软件？JPEG 图片压进压缩包体积会明显变小吗，为什么？

## 术语中英对照

| 中文 | 英文 | 一句话说明 |
| --- | --- | --- |
| 压缩 | Compress | 用算法减小数据体积的过程 |
| 解压 / 提取 | Extract | 从压缩包中还原出原始文件 |
| 压缩包 / 归档 | Archive | 打包多个文件形成的一个文件（如 .zip） |
| 无损压缩 | Lossless Compression | 解压后数据与原来完全一致 |
| 有损压缩 | Lossy Compression | 牺牲部分数据换取更小体积（JPEG、MP3） |
| 压缩率 | Compression Ratio | 压缩后体积与原始体积的比值 |
| 加密 | Encryption | 用密码保护文件，无密码无法读取 |
