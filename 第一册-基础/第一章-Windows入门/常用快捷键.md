# 常用快捷键：第一章 认识你的电脑

> 本章操作对应的快捷键。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——**Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`**（表格中仍写 Ctrl，另列 macOS 特有键位）。

## 一、系统操作

| 平台 | 快捷键 | 作用 |
|---|---|---|
| Windows | `Win + E` | 打开文件资源管理器 |
| macOS | `Cmd + Space` | 聚焦搜索（Spotlight），可快速打开应用、搜索文件 |
| Windows | `Win + D` | 显示/隐藏桌面 |
| Windows | `Alt + Tab` | 切换窗口 |
| macOS | `Cmd + Tab` | 切换应用 |
| Windows | `Win + Shift + S` | 区域截图并复制到剪贴板 |
| macOS | `Cmd + Shift + 3` / `4` / `5` | 全屏截图 / 区域截图 / 打开截图工具条 |
| Windows | `Win + L` | 锁定电脑 |
| macOS | `Ctrl + Cmd + Q` | 锁定屏幕 |
| Windows | `Ctrl + Shift + Esc` | 打开任务管理器 |
| macOS | `Cmd + Option + Esc` | 强制退出应用 |
| 通用 | `Ctrl + C` / `X` / `V` | 复制 / 剪切 / 粘贴 |
| Windows | `Win + V` | 剪贴板历史（需先在设置中开启） |

## 二、VS Code

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Ctrl + Shift + P` | 命令面板（最核心） |
| 通用 | `Ctrl + P` | 快速打开文件 |
| 通用 | `` Ctrl + ` `` | 打开/关闭集成终端 |
| 通用 | `Ctrl + Shift + V` | Markdown 预览 |
| 通用 | `Ctrl + K V` | Markdown 并排预览 |
| 通用 | `Ctrl + B` | 显示/隐藏侧边栏 |
| 通用 | `Ctrl + /` | 注释/取消注释 |
| 通用 | `Alt + 点击` | 多光标编辑（macOS 为 `Option + 点击`） |
| 通用 | `F2` | 重命名符号 |

> 上表中「通用」行的 `Ctrl` 在 macOS 上对应 `Cmd`（如命令面板为 `Cmd+Shift+P`）；`Alt` 对应 `Option`。
