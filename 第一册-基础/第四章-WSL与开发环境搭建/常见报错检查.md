# 常见报错检查：第四章 WSL 与开发环境搭建

> 本章是全书报错最多的一章，遇到报错先看这张表，再对照正文。OpenCode 相关报错见[第五章的常见报错检查](../第五章-OpenCode编程代理/常见报错检查.md)；全部章节的汇总见[附录《常见报错速查表》](../../附录-速查总览/常见报错速查表.md)。

## 一、WSL 安装类

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `0x80370102`（提示"请启用虚拟机平台"） | 未启用"虚拟机平台"功能，或 BIOS 虚拟化关闭 | 管理员 PowerShell 执行 `dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart`，重启；BIOS 中开启 VT-x/AMD-V | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `0x80070003` 安装失败 | 发行版装在非系统盘（WSL 仅支持 C 盘） | 设置→存储→新内容的保存位置改回 C 盘；旧 CPU 需支持 SLAT | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `0x800701bc`（"WSL 2 需要更新其内核组件"） | 内核更新包缺失或过旧 | 管理员 PowerShell 运行 `wsl --update`，或下载安装内核更新 MSI 包 | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `wsl --install` 卡在 0.0% 或只显示帮助文本 | 已装过 WSL，或商店下载失败 | `wsl --list --online` 查看列表；改用 `wsl --install --web-download -d Ubuntu` | [WSL 安装](https://learn.microsoft.com/zh-cn/windows/wsl/install) |

## 二、apt、软件源与网络类

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `E: Unable to locate package xxx` | 软件源索引未更新或源不可达 | 先 `sudo apt update` 再安装；仍失败可换国内镜像源 | [Ubuntu 包管理](https://ubuntu.com/server/docs/how-to/software/package-management/) |
| 更新/下载速度极慢 | 官方源在境外 | 换国内镜像源（清华、阿里云） | [WSL 使用](./WSL-使用.md) |
| `curl: Failed to connect to ... port 443` / `Could not resolve host` | 网络不通或 DNS 故障 | `ping 域名` 排查；检查 VPN/代理设置；WSL 中可先 `sudo apt update` | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `SSL certificate verify failed`（curl/wget） | 系统证书过期 | `sudo apt install ca-certificates` 更新证书；临时可用 `wget --no-check-certificate` | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |

## 三、mamba/conda 与 Python 类

| 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|
| `command not found: mamba` 或 `command not found: conda` | mamba/conda 未初始化 | `source ~/.bashrc`；或重跑安装脚本并确认初始化选 `yes` | [Miniforge 安装](https://github.com/conda-forge/miniforge/releases) |
| `PackagesNotFoundError: ... not available from current channels` | 包名拼写错误，或包不在默认渠道 | `mamba search 包名` 核对拼写；`mamba install -c conda-forge 包名`，或 `mamba config --append channels conda-forge` 后重试 | [管理渠道](https://docs.conda.io/projects/conda/en/latest/user-guide/tasks/manage-channels.html) |
| `CondaHTTPError: HTTP 000 CONNECTION FAILED` | 网络无法连接 repo.anaconda.com | 检查网络/代理；配置清华镜像源后重试 | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| `SSL: CERTIFICATE_VERIFY_FAILED` | 证书验证失败（代理/公司网络常见） | `sudo apt install ca-certificates` 更新证书；临时可用 `wget --no-check-certificate` | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
