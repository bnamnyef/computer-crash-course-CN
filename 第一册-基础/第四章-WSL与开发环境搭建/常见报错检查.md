# 常见报错检查：第四章 终端与开发环境

> 本章是全书报错最多的一章，遇到报错先看这张表，再对照正文。OpenCode 相关报错见[第五章的常见报错检查](../第五章-OpenCode编程代理/常见报错检查.md)；全部章节的汇总见[附录《常见报错速查表》](../../附录-速查总览/常见报错速查表.md)。
>
> 「平台」列说明：`通用` = 两个平台都会遇到；`Windows` / `macOS` = 该平台专有（含命令写法差异，如 `~/.bashrc` 与 `~/.zshrc`）。

## 一、WSL 安装类（Windows 专属，macOS 无此步骤）

| 平台 | 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|---|
| Windows | `0x80370102`（提示"请启用虚拟机平台"） | 未启用"虚拟机平台"功能，或 BIOS 虚拟化关闭 | 管理员 PowerShell 执行 `dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart`，重启；BIOS 中开启 VT-x/AMD-V | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| Windows | `0x80070003` 安装失败 | 发行版装在非系统盘（WSL 仅支持 C 盘） | 设置→存储→新内容的保存位置改回 C 盘；旧 CPU 需支持 SLAT | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| Windows | `0x800701bc`（"WSL 2 需要更新其内核组件"） | 内核更新包缺失或过旧 | 管理员 PowerShell 运行 `wsl --update`，或下载安装内核更新 MSI 包 | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| Windows | `wsl --install` 卡在 0.0% 或只显示帮助文本 | 已装过 WSL，或商店下载失败 | `wsl --list --online` 查看列表；改用 `wsl --install --web-download -d Ubuntu` | [WSL 安装](https://learn.microsoft.com/zh-cn/windows/wsl/install) |

## 二、apt / brew、软件源与网络类

| 平台 | 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|---|
| Windows | `E: Unable to locate package xxx` | 软件源索引未更新或源不可达 | 先 `sudo apt update` 再安装；仍失败可换国内镜像源 | [Ubuntu 包管理](https://ubuntu.com/server/docs/how-to/software/package-management/) |
| 通用 | 更新/下载速度极慢 | 官方源在境外 | Windows：换 apt 国内镜像源（清华、阿里云）与 conda 镜像；macOS：见 Homebrew 官方文档的 Git remote mirroring 与本文第四节的镜像配置 | [WSL 使用](./WSL-使用.md) / [Homebrew Installation](https://docs.brew.sh/Installation) |
| 通用 | `curl: Failed to connect to ... port 443` / `Could not resolve host` | 网络不通或 DNS 故障 | `ping 域名` 排查；检查 VPN/代理设置 | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| 通用 | `SSL certificate verify failed`（curl/wget） | 系统证书过期或代理拦截 | Windows/WSL：`sudo apt install ca-certificates`；macOS：`brew install ca-certificates` 或检查代理证书 | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| macOS | `zsh: command not found: brew` | 安装后未把 brew 加入 PATH | 按安装脚本提示把 `eval "$(/opt/homebrew/bin/brew shellenv)"` 写入 `~/.zprofile` 并重开终端（Intel 为 `/usr/local`） | [终端与 Homebrew](./终端与Homebrew-macOS.md) |
| macOS | Homebrew 安装/更新卡住、`Failed to connect to github.com` | 官方源在境外 | 检查网络/代理；参考官方 Installation 的镜像配置；HTTP 代理可设置 `export ALL_PROXY=...` 后重试 | [Homebrew Troubleshooting](https://docs.brew.sh/Troubleshooting) |
| macOS | `xcrun: error: invalid active developer path` / `git: command not found` | 缺少 Xcode Command Line Tools（brew 与 git 的前置依赖） | 运行 `xcode-select --install`，按弹窗提示安装后重试 | [Homebrew Installation](https://docs.brew.sh/Installation) |
| macOS | `Permission denied` / `Operation not permitted`（装软件或改配置文件时） | 权限不足，或目标是受系统保护的位置 | 不要对系统目录强行提权；优先装到用户目录（如 Miniforge 默认 `~/miniforge3`）；确需系统级操作再用 `sudo` | [Python 环境配置（macOS 版）](./Python-环境配置-macOS.md) |

## 三、mamba/conda 与 Python 类

| 平台 | 报错信息 | 常见原因 | 排查与解决 | 参考 |
|---|---|---|---|---|
| Windows | `command not found: mamba` 或 `command not found: conda` | mamba/conda 未初始化（WSL） | `source ~/.bashrc`；或重跑安装脚本并确认初始化选 `yes` | [Miniforge 安装](https://github.com/conda-forge/miniforge/releases) |
| macOS | `command not found: mamba` 或 `command not found: conda` | 初始化写入了 `~/.zshrc` 但当前窗口未刷新 | `source ~/.zshrc`；或运行 `~/miniforge3/bin/conda init zsh` 后重开终端 | [Python 环境配置（macOS 版）](./Python-环境配置-macOS.md) |
| 通用 | `PackagesNotFoundError: ... not available from current channels` | 包名拼写错误，或包不在默认渠道 | `mamba search 包名` 核对拼写；`mamba install -c conda-forge 包名`，或 `mamba config --append channels conda-forge` 后重试 | [管理渠道](https://docs.conda.io/projects/conda/en/latest/user-guide/tasks/manage-channels.html) |
| 通用 | `CondaHTTPError: HTTP 000 CONNECTION FAILED` | 网络无法连接 repo.anaconda.com | 检查网络/代理；配置清华镜像源后重试 | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| 通用 | `SSL: CERTIFICATE_VERIFY_FAILED` | 证书验证失败（代理/公司网络常见） | Windows/WSL：`sudo apt install ca-certificates`；macOS：`brew install ca-certificates`；临时可用 `--no-check-certificate` | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| macOS | Miniforge 安装报错或 conda 与 Homebrew 相互干扰 | 用 Homebrew 安装了 Miniforge（官方不推荐） | 卸载 Homebrew 版 Miniforge，按官方脚本重新安装 | [Miniforge 官方仓库](https://github.com/conda-forge/miniforge) |
