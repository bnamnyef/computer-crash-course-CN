# 第四章导读：先认识这些名词，再开始动手

> 本章是整本教程**难度最高**的一章：我们要在 Windows 里装一个 Linux（WSL）、学会用终端敲命令、再配置 Python 环境。如果你是纯新手，这一章你会看到大量新词——没关系，这篇导读先把它们解释清楚，让你心里有底再动手。

## 一、为什么要学这一章？

- 绝大多数开发工具（Python、Git、各类 AI 工具）在 Linux 环境下运行最顺畅，配置教程也最多；
- 终端命令是**通用技能**——不管以后学什么，都绕不开它；
- 学完本章，你就拥有了一套完整的开发环境，可以跟上互联网上绝大部分开发教程。

## 二、名词铺垫（先混个脸熟，不用背）

| 名词 | 一句话解释 | 生活比喻 |
|---|---|---|
| 虚拟化 / 虚拟机 | 用软件在电脑里"模拟"出另一台电脑 | 在房子里再隔出一间房 |
| WSL | Windows 官方提供的"在 Windows 里运行 Linux"的功能，全称 Windows Subsystem for Linux | Windows 里开的一扇通向 Linux 的门 |
| Linux | 开源操作系统，服务器和开发者世界的"标准语言"之一 | 另一个操作系统"国家" |
| Ubuntu / 发行版 | Ubuntu 是最流行的 Linux 版本；"发行版"指 Linux 的不同打包版本 | 同一系统的不同套餐 |
| 终端 / 命令行 | 用输入文字命令的方式操作电脑的窗口 | 对电脑念"咒语" |
| bash / shell | 终端里负责解释命令、执行命令的程序 | 翻译官 |
| sudo | 以管理员权限执行命令（sudo = superuser do） | 命令前加一句"以老板身份" |
| apt | Ubuntu 的软件包管理器，负责装/卸软件 | 命令行版的应用商店 |
| 软件源 | 存放软件包的服务器仓库（apt 从哪里拿软件） | 商店的货架 |
| Python | 最流行的编程语言之一，AI 生态的首选语言 | — |
| Miniforge / conda | Python 环境管理器：为每个项目隔离一套独立环境 | 每个项目一间独立房间 |
| 虚拟环境 | 互相隔离的 Python 环境，依赖互不干扰 | 项目专属小房间 |
| 镜像源 | 官方下载源的国内加速副本 | 家门口的分店 |

## 四、学这章之前的三句心理建设

1. **卡住是正常的**：环境配置类章节报错率最高，几乎所有初学者都会在这里折腾几次。报错不是你的错，是环境问题，附录速查表就是为你准备的。
2. **命令不用背**：没有人记得住所有命令，用多了自然记住；忘了就查「终端与命令行基础」里的命令表。
3. **学完你就是"开发者"了**：这一章之后，互联网上绝大多数开发教程你都能跟上——这一章的难度，恰恰说明你在跨越最重要的门槛。
