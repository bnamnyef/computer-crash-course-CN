# 常用快捷键：第四章 终端与开发环境

> 本章的日常操作都在终端里完成，这些快捷键能显著提升效率（来源为 GNU Bash、Windows Terminal 与 Apple 终端官方文档）。全书的汇总见[附录《常用快捷键汇总表》](../../附录-速查总览/常用快捷键汇总表.md)。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`。

## 一、终端命令行编辑（bash / zsh / Readline，两平台通用）

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Tab` | 自动补全命令或文件名（最常用；连按两次列出候选） |
| 通用 | `↑` / `↓` | 翻看上一条 / 下一条命令历史 |
| 通用 | `Ctrl + C` | 中断当前正在运行的命令 |
| 通用 | `Ctrl + L` | 清屏（macOS 终端也可用 `Cmd + K`） |
| 通用 | `Ctrl + A` / `Ctrl + E` | 光标跳到行首 / 行尾 |
| 通用 | `Ctrl + U` | 删除光标前的整行 |
| 通用 | `Ctrl + K` | 删除光标到行尾 |
| 通用 | `Ctrl + W` | 删除光标前的一个词 |
| 通用 | `Ctrl + R` | 反向搜索历史命令 |

## 二、Windows Terminal（Windows）

| 平台 | 快捷键 | 作用 |
|---|---|---|
| Windows | `Ctrl + Shift + T` | 新建标签页 |
| Windows | `Ctrl + Shift + W` | 关闭标签页 |
| Windows | `Ctrl + Tab` | 在标签页之间切换 |
| Windows | `Ctrl + Shift + C` / `Ctrl + Shift + V` | 复制 / 粘贴（Ctrl+C 被保留给中断） |

## 三、macOS 自带「终端」（Terminal）

| 平台 | 快捷键 | 作用 |
|---|---|---|
| macOS | `Cmd + T` | 新建标签页 |
| macOS | `Cmd + N` | 新建窗口 |
| macOS | `Cmd + W` | 关闭标签页 |
| macOS | `Cmd + D` | 将窗口拆分为两个面板 |
| macOS | `Control + Tab` | 切换到下一个标签页 |
| macOS | `Cmd + K` | 清屏（清除到开头） |
| macOS | `Cmd + C` / `Cmd + V` | 复制 / 粘贴 |
| macOS | `Cmd + F` | 查找 |
| macOS | `Cmd + .` | 中断（等价于 `Ctrl + C`） |

## 四、VS Code 集成终端

| 平台 | 快捷键 | 作用 |
|---|---|---|
