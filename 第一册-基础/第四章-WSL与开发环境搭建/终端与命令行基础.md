# 终端与命令行基础

### 本章学完你能做什么

- 理解为什么 Git、conda、OpenCode 这些工具都是命令行程序
- 熟练使用 bash 常用命令（目录/文件/搜索/管道/重定向）
- 用 `man` 和 `--help` 自学任何命令
- 看懂并临时修改 PATH 环境变量

## 一、为什么学终端？

图形界面能做的事，终端几乎都能做，而且更快、更适合批量操作与远程服务器。关键是：**后续要用的工具（Git、Miniforge、OpenCode）都是命令行程序**。把常用操作从「鼠标」翻译成「命令」，就掌握了终端。

| 图形界面操作 | 终端命令 |
|---|---|
| 打开文件夹 | `cd 文件夹` |
| 查看文件夹里有什么 | `ls`（Windows 用 `dir`） |
| 新建文件夹 | `mkdir 新文件夹` |
| 复制/移动/删除 | `cp`、`mv`、`rm` |
| 查看文件内容 | `cat`、`less` |

## 二、bash 常用命令分类总结

Ubuntu 默认的 shell 是 bash（Ubuntu 官方教程说明）。以下命令均可输入 `man 命令名` 查看详细手册：

**目录与文件**

| 命令 | 作用 | 示例 |
|---|---|---|
| `pwd` | 显示当前路径 | `pwd` |
| `cd` | 切换目录（无参数回主目录） | `cd ~/Desktop` |
| `ls` | 列出文件（`-l` 详细、`-a` 含隐藏文件） | `ls -la` |
| `mkdir` | 新建文件夹（`-p` 可建多级） | `mkdir -p a/b/c` |
| `touch` | 新建空文件 | `touch hello.py` |
| `cp` | 复制 | `cp a.txt b.txt` |
| `mv` | 移动/重命名 | `mv a.txt dir/` |
| `rm` | 删除（**不可恢复**，删文件夹需 `-r`） | `rm -r 文件夹` |

**查看内容**：`cat 文件`（全部输出）、`less 文件`（分页浏览，按 `q` 退出）、`head -n 10`（前 10 行）、`tail -n 10`（后 10 行，`tail -f` 实时跟踪日志）。

**搜索**：`grep 关键词 文件` 在文件中搜索文本，如 `grep "error" log.txt`。

**权限**：`sudo 命令` 以管理员身份执行（首次会提示输密码）；`chmod` 修改文件权限（本章只需知道概念，遇到 "Permission denied" 时先想到 `sudo`）。

**管道与重定向**（GNU coreutils 官方手册有专门章节）：

- `命令1 | 命令2`：把命令 1 的输出喂给命令 2，如 `ls | grep py`。
- `> 文件`：把输出写入文件（覆盖）；`>> 文件`：追加到文件末尾。
- `< 文件`：从文件读取输入。

**进程控制**：`Ctrl+C` 中断当前命令；`Ctrl+Z` 挂起；`jobs` 查看后台任务；`ps aux` 列出进程。

**帮助**：`man 命令名` 打开手册（按 `q` 退出）；`命令 --help` 显示简要用法（coreutils 官方文档说明所有 GNU 命令都支持）。

## 四、环境变量：echo $PATH

环境变量是系统记住的全局设置，PATH 记录「敲命令时去哪找程序」。查看方式：

```bash
echo $PATH
```

输出是一串用冒号分隔的目录（如 `/usr/local/bin:/usr/bin:...`）。之前安装 Miniforge 时 `source ~/.bashrc` 把 conda 目录加入 PATH，所以重启终端后直接敲 `conda` 就能用——这就是 PATH 的作用。临时修改：`export PATH="$PATH:/新目录"`。

> 环境变量与 PATH 的完整讲解见 [Windows 文件管理系统](../第一章-Windows入门/Windows-文件管理系统.md)，路径概念见 [文件路径](../第一章-Windows入门/文件路径.md)。

## 小结与练习

1. 用 `mkdir -p test/a/b` 创建多级目录，`touch test/a/b/hello.txt` 建文件，`ls -la test/a` 查看。
2. 用管道组合命令：`ls | grep txt`，再试试 `ls | head -n 3`。
3. 用 `ls > 文件列表.txt` 把输出保存到文件，再用 `cat 文件列表.txt` 查看内容。
4. 自查：`Tab`、`Ctrl+C`、`Ctrl+Z`、`↑` 分别干什么？答案见本章的[《常用快捷键》](./常用快捷键.md)；`man` 手册里按什么键退出？

## 术语中英对照

| 中文 | 英文 | 一句话说明 |
|---|---|---|
| 终端 | Terminal | 敲命令与系统交互的窗口 |
| 命令行解释器 | Shell | 解释并执行你输入命令的程序（Ubuntu 默认 bash） |
| 管道 | Pipe（`|`） | 把一个命令的输出接到下一个命令 |
| 重定向 | Redirection（`>`、`>>`） | 把命令输出写入文件 |
| 进程 | Process | 正在运行的程序实例 |
| 权限 | Permission | 文件/命令的访问控制（`sudo` 临时提升） |
| 手册 | Manual（man） | 命令的官方使用说明文档 |
