# 常用快捷键：第五章 Git 与 VS Code

> Git 是命令行工具，没有"快捷键"，但配合 VS Code 和终端历史功能能省很多事。全书的汇总见[附录《常用快捷键汇总表》](../附录-速查总览/常用快捷键汇总表.md)。

## 一、VS Code 与 Git

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Shift + G` | 打开「源代码管理」面板（查看改动、输入提交信息） |
| `Ctrl + Shift + P` 输入 `Git:` | 执行 Git 相关命令（如 Git: Commit、Git: Push） |
| 代码行上悬停 | GitLens 插件：显示这行是谁、什么时候改的（blame） |

## 二、终端里操作 Git

| 快捷键 | 作用 |
|---|---|
| `↑` / `↓` | 翻看历史命令（重复执行 `git status` 等） |
| `Ctrl + R` | 反向搜索历史命令（输入 `push` 找回上次的推送命令） |
| `Tab` | 补全分支名、文件名 |
