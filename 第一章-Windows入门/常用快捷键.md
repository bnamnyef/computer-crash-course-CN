# 常用快捷键：第一章 Windows 入门

> 本章操作对应的快捷键。全书的汇总见[附录《常用快捷键汇总表》](../附录-速查总览/常用快捷键汇总表.md)。

## 一、Windows 系统

| 快捷键 | 作用 |
|---|---|
| `Win + E` | 打开文件资源管理器 |
| `Win + D` | 显示/隐藏桌面 |
| `Alt + Tab` | 切换窗口 |
| `Win + Shift + S` | 区域截图并复制到剪贴板 |
| `Win + L` | 锁定电脑 |
| `Ctrl + Shift + Esc` | 打开任务管理器 |
| `Ctrl + C` / `X` / `V` | 复制 / 剪切 / 粘贴 |
| `Win + V` | 剪贴板历史（需先在设置中开启） |

## 二、VS Code

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Shift + P` | 命令面板（最核心） |
| `Ctrl + P` | 快速打开文件 |
| `` Ctrl + ` `` | 打开/关闭集成终端 |
| `Ctrl + Shift + V` | Markdown 预览 |
| `Ctrl + K V` | Markdown 并排预览 |
| `Ctrl + B` | 显示/隐藏侧边栏 |
| `Ctrl + /` | 注释/取消注释 |
| `Alt + 点击` | 多光标编辑 |
| `F2` | 重命名符号 |
