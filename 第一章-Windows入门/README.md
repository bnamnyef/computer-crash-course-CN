# 第一章导读：先认识你的电脑

> 本章是全书的地基：认识 Windows 文件系统与路径、理解环境变量，装好 VS Code 并用 Markdown 记笔记。如果你是纯新手，先把这一章走完，后面的章节会顺畅很多。

## 一、为什么要学这一章？

- 文件、路径、环境变量是电脑操作的**通用语言**，后续所有章节（WSL、Python、Git）都在这个基础上展开；
- VS Code 是之后写笔记、写代码的"主战场"，本章先把它装好并学会项目管理式使用；
- Markdown 是程序员写文档的通用格式，学会它，本教程的笔记你就可以自己动手写了。

## 二、名词铺垫（先混个脸熟，不用背）

| 名词 | 一句话解释 | 生活比喻 |
|---|---|---|
| 操作系统 | 管理电脑硬件与软件的底层系统（Windows 11 等） | 电脑的"大管家" |
| 文件系统 | 组织和存储文件的规则（NTFS 等） | 资料库的"分类规则" |
| 路径 | 文件在电脑中的"地址" | 门牌号 |
| 压缩包 | 把多个文件打包压缩成一个文件（如 .zip） | 装行李的"行李箱" |
| 环境变量 | 系统记住的全局设置（PATH 最常见） | 给电脑的"备忘便签" |
| PATH | 告诉系统"敲命令时去哪找程序" | 命令的"寻人启事" |
| Markdown | 用符号标记格式的轻量级标记语言（.md） | 写文档的"速记符号" |
| 工作区 | VS Code 中打开的一个或多个文件夹 | 一张"办公桌" |
| 扩展 / 插件 | 给 VS Code 增加功能的组件 | 应用的"外挂模块" |

## 四、学习建议

1. **边读边做**：环境变量、PATH 这类操作只看不动手等于没学，照着正文各做一遍。
2. **把 VS Code 用起来**：装好后立刻用它打开本教程文件夹，边读第一章边写你自己的 Markdown 笔记。
3. **报错不可怕**：环境变量类报错 90% 是"没重启窗口"或"路径没加对"，对照「常见报错检查」逐条查。
