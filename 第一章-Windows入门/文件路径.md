# 文件路径：给文件一个「地址」

### 本章学完你能做什么

- 说清楚什么是路径，区分绝对路径与相对路径（含 `.` 和 `..` 的含义）
- 对比 Windows 与 Linux 的路径风格，看懂两种系统的地址栏
- 在 Windows 与 WSL 之间互相访问文件（`/mnt/c`、`\\wsl$`）
- 通过 PATH 环境变量，让程序"敲名字就能运行"

## 一、什么是路径

路径就是文件在电脑中的「地址」，它告诉系统文件存放在哪个盘、哪个文件夹里。文件资源管理器顶部的地址栏显示的 `C:\Users\小明\Documents\report.docx`，就是一个路径。学会看路径，是理解文件系统与命令行操作的第一步。

## 二、绝对路径与相对路径

- **绝对路径**：从根目录开始写全，无论当前在哪都能准确定位。Windows 如 `C:\Users\xiaoming\Documents\report.docx`，Linux 如 `/home/xiaoming/Documents/report.docx`。
- **相对路径**：相对「当前所在目录」来描述位置，结果随当前位置变化。
- **`.` 与 `..`**：根据 Microsoft Learn 官方定义，单个句点 `.` 代表当前目录，双句点 `..` 代表父目录。例如 `cd ..` 表示「回到上一级目录」，`mv file .` 表示「把文件移到当前目录」。

| 写法 | 含义 |
|---|---|
| `C:\Users\...` / `/home/...` | 绝对路径 |
| `Documents\report.docx` / `Documents/report.docx` | 相对当前目录 |
| `.` | 当前目录 |
| `..` | 上一级（父）目录 |
| `~`（Linux） | 当前用户的主目录（如 /home/用户名） |

## 三、Windows 与 Linux 路径风格对比

| 项目 | Windows | Linux（含 WSL） |
|---|---|---|
| 示例 | `C:\Users\me\Project` | `/home/me/Project` |
| 分隔符 | 反斜杠 `\` | 正斜杠 `/` |
| 盘符 | 每个盘一个字母（C:、D:） | 无盘符，所有磁盘统一挂载在根 `/` 下 |
| 根目录 | 每盘一个根（`C:\`） | 唯一的根 `/` |
| 大小写 | 不区分（`Foo.txt` 与 `foo.txt` 视为同一文件） | 区分（两者是不同的文件） |

## 四、WSL 中访问对方的文件

- **在 WSL（Linux）中访问 Windows 文件**：Windows 的磁盘会以「挂载」方式出现在 `/mnt/` 下。C 盘就是 `/mnt/c/`，例如 `cd /mnt/c/Users/你的用户名/Desktop` 即可进入 Windows 桌面。
- **在 Windows 中访问 WSL 文件**：打开文件资源管理器，在地址栏输入 `\\wsl$` 回车，即可看到所有已安装的 Linux 发行版及其根文件系统（微软官方文档提供的方式）。
- **快捷互跳**：在 WSL 终端输入 `explorer.exe .` 可直接用资源管理器打开当前目录。
- **性能提示**：微软官方建议，WSL 项目文件应存放在 Linux 文件系统（如 `/home/用户名/Project`），跨系统读写（如 `/mnt/c/...`）速度较慢。

> 还没装 WSL？先去 [WSL 安装](../第四章-WSL与开发环境搭建/WSL-安装.md) 学会装一个轻量 Linux，再回来体验文件互访。

## 五、PATH 实操：敲名字就能运行程序

系统靠一个叫 PATH 的环境变量记住「程序放在哪些文件夹」。当程序所在目录已加入 PATH，命令行里直接敲程序名即可运行，无需写完整路径：

- **Windows**：设置 → 系统 → 关于 → 高级系统设置 → 环境变量 → 编辑「Path」，把程序目录加进去，重启终端后生效（这也是 VS Code 安装时勾选 Add to PATH 的原因）。
- **WSL**：`echo $PATH` 可查看当前搜索路径；临时添加可用 `export PATH="$PATH:/home/me/bin"`。

## 六、常用路径命令速查

| 命令 | 作用 | Windows 对应 |
|---|---|---|
| `pwd` | 显示当前所在路径 | `cd`（无参数） |
| `cd 路径` | 切换目录 | `cd` |
| `ls` / `ls -la` | 列出文件（-a 含隐藏文件） | `dir` |
| `mkdir 目录名` | 新建文件夹 | 右键新建文件夹 |

## 小结与练习

1. 在 WSL 终端里分别用绝对路径（`cd /home/用户名`）和相对路径（`cd ~`）回到主目录，体会两者的区别。
2. 用 `cd /mnt/c/Users/` 进入你的 Windows 用户文件夹，用 `ls` 看看里面有什么。
3. 把某个程序目录加入 PATH（Windows 图形界面或 WSL 的 `export PATH` 均可），重启终端后验证"敲名字就能运行"。
4. 自查：`.` 和 `..` 分别代表什么？Windows 与 Linux 的路径分隔符分别是什么？

## 术语中英对照

| 中文 | 英文 | 一句话说明 |
|---|---|---|
| 路径 | Path | 文件在电脑中的"地址" |
| 绝对路径 | Absolute Path | 从根目录写起的完整地址 |
| 相对路径 | Relative Path | 相对当前目录的地址 |
| 根目录 | Root Directory | 路径的最顶层（Windows 每盘一个，Linux 唯一 `/`） |
| 父目录 | Parent Directory | 上一级目录（`..`） |
| 主目录 | Home Directory | 当前用户的家（Linux 为 `/home/用户名`，即 `~`） |
| 挂载 | Mount | 把磁盘/目录接入文件系统的过程（如 `/mnt/c`） |
| 环境变量 | Environment Variable | 系统级设置项，PATH 是其中最常见的一个 |
