## 第一章：Windows 与常用软件

| 报错现象 | 常见原因 | 排查与解决 | 官方参考链接 |
|---|---|---|---|
| 修改环境变量后不生效 | 已打开的程序/窗口不会自动刷新 | 重启命令行窗口或程序后再验证 | [环境变量](https://learn.microsoft.com/zh-cn/windows/win32/procthread/environment-variables) |
| `echo %变量%` 原样显示 | 终端类型不对或变量不存在 | cmd 用 `%名%`，PowerShell 用 `$env:名` | 同上 |
| `'xxx' 不是内部或外部命令`（cmd）/ `无法将"xxx"项识别为 cmdlet`（PowerShell） | 目录不在 PATH，或加了 PATH 没重启终端 | 加入 Path 后**重启**终端；核对路径拼写与目录是否存在 | [文件路径](../第一册-基础/第一章-Windows入门/文件路径.md) |
| `setx` 提示无效语法/参数过多 | 值里含空格未加引号 | 用双引号括起来：`setx 变量名 "含空格的值"` | [setx](https://learn.microsoft.com/zh-cn/windows-server/administration/windows-commands/setx) |
| setx 后当前窗口不生效 | setx 只对将来的窗口生效 | 新开命令行窗口验证 | 同上 |
| setx 修改 PATH 后系统命令大面积失效 | 用 `%Path%` 回写被截断到 1024 字符，覆盖了系统 Path | 图形界面恢复完整 Path；勿用 `%Path%` 整体回写 setx | 同上 |
| 编辑系统变量时拒绝访问 | 系统变量需要管理员权限 | 用管理员账户操作 | [Windows 文件管理系统](../第一册-基础/第一章-Windows入门/Windows-文件管理系统.md) |
| 用户变量对服务/其他账户不可见 | 用户变量只对当前账户生效 | 需要全局生效时加到系统变量 | 同上 |
| WSL 终端里 `code` 不可用 | 安装时未勾选 Add to PATH | 重装勾选或手动加 PATH | [软件安装-VSCode](../第一册-基础/第一章-Windows入门/软件安装-VSCode.md) |
| Markdown 表格/任务列表预览不显示 | VS Code 预览遵循 CommonMark，表格是 GFM 扩展 | 以 GitHub 渲染为准 | [CommonMark](https://spec.commonmark.org/) |

## 第二章：AI-API 调用（DeepSeek / 硅基流动）

| 报错信息 | 常见原因 | 排查与解决 | 官方参考链接 |
|---|---|---|---|
| `401 Authentication Fails` | API Key 错误或未创建 | 到平台 API 密钥页重新创建并复制 | [DeepSeek 错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes) |
| `402 Insufficient Balance` | 余额不足 | 充值（硅基流动需先实名认证） | 同上 |
| `429 Too Many Requests` | 请求速率达上限 | 降低频率、错峰请求 | 同上 |
| 模型名报错 | 用了已下线的旧模型名 | 以官方「模型 & 价格」页为准 | [DeepSeek 模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) |
| 连接失败/超时 | base_url 填错或网络问题 | 核对 base_url 与网络 | [AI-API 使用](../第一册-基础/第二章-AI-API入门/AI-API-使用.md) |
| API Key 泄露 | 误发到公开场合 | 立即吊销并重新生成 | 同上 |

## 第三章：照着教程报错（四查清单）

| 检查项 | 问自己 | 处理 |
|---|---|---|
| 版本匹配 | 教程发布时间？版本与我一致吗？ | 对照官方文档当前写法 |
| 命令安全 | 每条命令看得懂吗？含 `sudo`、`curl \| bash`、`rm`？ | 弄懂再执行，不理解不执行 |
| 结果验证 | 教程说成功就算成功？ | 用验证命令自查，以结果为准 |
| 来源核实 | 域名是官方吗？ | 官方优先，社区多篇对照 |

## 第四章：WSL 与开发环境

| 报错信息 | 常见原因 | 排查与解决 | 官方参考链接 |
|---|---|---|---|
| `0x80370102`（请启用虚拟机平台） | 未启用虚拟机平台或 BIOS 虚拟化关闭 | `dism.exe ... /featurename:VirtualMachinePlatform` 启用后重启；BIOS 开 VT-x/AMD-V | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `0x80070003` 安装失败 | 发行版装在非系统盘 | 新内容保存位置改回 C 盘 | 同上 |
| `0x800701bc`（需要更新内核） | WSL 内核过旧 | `wsl --update` | 同上 |
| `wsl --install` 卡在 0.0% | 商店下载失败 | `wsl --install --web-download -d Ubuntu` | [WSL 安装](https://learn.microsoft.com/zh-cn/windows/wsl/install) |
| `E: Unable to locate package` | 索引未更新或源不可达 | `sudo apt update`；换国内镜像 | [Ubuntu 包管理](https://ubuntu.com/server/docs/how-to/software/package-management/) |
| `curl: Failed to connect to ... port 443` / `Could not resolve host` | 网络不通或 DNS 故障 | `ping 域名` 排查；检查 VPN/代理 | [WSL 排障](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting) |
| `SSL certificate verify failed`（curl/wget） | 系统证书过期 | `sudo apt install ca-certificates` | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| `command not found: mamba` 或 `command not found: conda` | mamba/conda 未初始化 | `source ~/.bashrc` 或重装选 yes | [Miniforge](https://github.com/conda-forge/miniforge/releases) |
| `PackagesNotFoundError` | 包名拼错或不在渠道 | `mamba search` 核对；`-c conda-forge` | [管理渠道](https://docs.conda.io/projects/conda/en/latest/user-guide/tasks/manage-channels.html) |
| `CondaHTTPError: HTTP 000` | 网络连不上官方源 | 配置清华镜像；检查代理 | [conda 排障](https://docs.conda.io/projects/conda/en/latest/user-guide/troubleshooting.html) |
| `opencode: command not found` | 未安装或 PATH 不含安装目录 | 重跑官方安装脚本，重启终端 | [OpenCode](https://opencode.ai/docs/) |

## 第六章：Vim（选修）

| 报错信息 / 现象 | 常见原因 | 排查与解决 | 官方参考链接 |
|---|---|---|---|
| `vim: command not found` | 未安装 Vim | `sudo apt install vim` | [Vim 官方文档](https://www.vim.org/docs.php) |
| `E325: ATTENTION`（交换文件 `.xxx.swp`） | 崩溃/断连留下交换文件，或文件已在另一窗口打开 | 确认后删除 `.swp`；恢复内容用 `vim -r 文件名` | [崩溃恢复](https://vimhelp.org/usr_11.txt.html#ATTENTION) |
| `E45: 'readonly' option is set` | 文件只读或无写权限 | 用 `sudo vim 文件`；或执行 `:w !sudo tee %` | [E45](https://vimhelp.org/message.txt.html#E45) |
| `E37: No write since last change` | 有未保存修改却执行 `:q` | 要保存用 `:wq`；不要就 `:q!` | [E37](https://vimhelp.org/message.txt.html#E37) |
| `E212: Can't open file for writing` | 目录不存在或无写权限 | 核对路径；系统目录用 `sudo vim` | [E212](https://vimhelp.org/message.txt.html#E212) |
| 按键"打不出字"或行为奇怪 | 不在正确的模式 | 先按 `Esc` 回普通模式 | [Vim 入门](../第二册-进阶/第六章-Vim/Vim-入门.md) |
| 粘贴代码时缩进乱掉 | 自动缩进与终端粘贴冲突 | `:set paste` 后再粘贴，完后 `:set nopaste` | [:set paste](https://vimhelp.org/options.txt.html#%27paste%27) |
| 中文显示乱码 | 编码不是 UTF-8 或识别错误 | `:set encoding=utf-8`；文件编码不对用 `:e ++enc=utf-8` 重开 | [:set encoding](https://vimhelp.org/options.txt.html#%27encoding%27) |
| 误删 / 改坏内容 | 误操作 | `u` 撤销、`Ctrl + r` 重做；崩溃后 `vim -r 文件名` 恢复 | [撤销 undo](https://vimhelp.org/undo.txt.html) |
