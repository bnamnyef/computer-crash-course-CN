# 常用快捷键汇总表

> 归入「附录-速查总览」，汇总两册七章（含选修第七章 Vim）的「常用快捷键」。每章正文都有一份对应的快捷键表（「常用快捷键.md」），本表按章节汇总全部条目。来源为各官方文档，链接已于 2026 年 8 月访问验证（OpenCode 相关链接于 2026 年 9 月补充验证，macOS 相关链接于 2026 年 9 月补充验证）。
>
> 「平台」列说明：`通用` = 两平台按键一致；仅修饰键不同的也按 `通用` 处理——**Windows 的 `Ctrl` 在 macOS 上对应 `Cmd`**（`Alt` 对应 `Option`，表格中仍写 Ctrl/Alt，另列 macOS 特有键位）。OpenCode 与 Vim 运行在终端里，键位与系统无关（不适用 Ctrl→Cmd 的换算）。**章内速查表与本表是有意设计的两级结构，修改条目时两处需同步。**

## 第一章：系统操作与 VS Code

### 系统操作

| 平台 | 快捷键 | 作用 |
|---|---|---|
| Windows | `Win + E` | 打开文件资源管理器 |
| macOS | `Cmd + Space` | 聚焦搜索（Spotlight） |
| Windows | `Win + D` | 显示/隐藏桌面 |
| Windows | `Alt + Tab` | 切换窗口 |
| macOS | `Cmd + Tab` | 切换应用 |
| Windows | `Win + Shift + S` | 区域截图 |
| macOS | `Cmd + Shift + 3` / `4` / `5` | 全屏截图 / 区域截图 / 截图工具条 |
| Windows | `Win + L` | 锁定电脑 |
| macOS | `Ctrl + Cmd + Q` | 锁定屏幕 |
| Windows | `Ctrl + Shift + Esc` | 打开任务管理器 |
| macOS | `Cmd + Option + Esc` | 强制退出应用 |
| 通用 | `Ctrl + C` / `X` / `V` / `Z` | 复制 / 剪切 / 粘贴 / 撤销 |
| Windows | `Win + V` | 剪贴板历史 |

### VS Code

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Ctrl + Shift + P` | 命令面板 |
| 通用 | `Ctrl + P` | 快速打开文件 |
| 通用 | `` Ctrl + ` `` | 集成终端 |
| 通用 | `Ctrl + Shift + V` / `Ctrl + K V` | Markdown 预览 / 并排预览 |
| 通用 | `Ctrl + B` | 侧边栏 |
| 通用 | `Ctrl + /` | 注释/取消注释 |
| 通用 | `Alt + 点击` | 多光标（macOS 为 `Option + 点击`） |
| 通用 | `F2` | 重命名符号 |

## 第五章：OpenCode（终端 TUI，键位与系统无关）

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Enter` | 发送消息 |
| 通用 | `Shift + Enter` / `Ctrl + J` | 输入换行（不发送） |
| 通用 | `Esc` | 中断正在生成的回复 |
| 通用 | `Tab` / `Shift + Tab` | 切换代理模式（Build / Plan） |
| 通用 | `Ctrl + P` | 打开命令列表 |
| 通用 | `Ctrl + X` 然后 `N` / `L` | 新建会话 / 会话列表 |
| 通用 | `Ctrl + X` 然后 `M` / `A` | 选择模型 / 切换代理 |
| 通用 | `Ctrl + X` 然后 `U` / `R` | 撤销 / 重做修改 |
| 通用 | `Ctrl + X` 然后 `E` / `Q` | 外部编辑器编辑 / 退出 |
| 通用 | `Ctrl + A` / `Ctrl + E` | 输入框行首 / 行尾 |
| 通用 | `Ctrl + U` / `Ctrl + K` | 删除光标前 / 光标后的内容 |
| 通用 | `Ctrl + W` | 删除前一个单词 |

> 在 VS Code 集成终端里按键被拦截（如 `Ctrl + P`）的处理方法，见[第五章常用快捷键](../第一册-基础/第五章-OpenCode编程代理/常用快捷键.md)第五节。

## 第七章：Vim（选修，键位与系统无关）

### 模式切换与普通模式

| 平台 | 快捷键 | 作用 |
|---|---|---|
| 通用 | `Esc` | 回到普通模式（迷路时先按它） |
| 通用 | `i` / `a` / `o` | 进入插入模式：光标前 / 光标后 / 下一行 |
| 通用 | `:` | 进入命令行模式 |
| 通用 | `v` / `V` | 可视模式 / 可视行模式 |
| 通用 | `h` `j` `k` `l` | 左 / 下 / 上 / 右移动光标 |
| 通用 | `gg` / `G` | 跳到文件开头 / 末尾 |
| 通用 | `0` / `$` | 行首 / 行尾 |
| 通用 | `/word` / `n` | 向下查找 / 下一个匹配 |
| 通用 | `x` / `dd` | 删除字符 / 删除整行 |
| 通用 | `yy` / `p` | 复制整行 / 粘贴 |
| 通用 | `u` / `Ctrl + r` | 撤销 / 重做 |
| 通用 | `.` | 重复上一次操作 |
| 通用 | `dw` / `ci"` | 删除一个单词 / 修改引号内的内容 |

### 命令行模式（保存与设置）

| 平台 | 命令 | 作用 |
|---|---|---|
| 通用 | `:w` / `:q` | 保存 / 退出 |
| 通用 | `:wq` 或 `ZZ` | 保存并退出 |
| 通用 | `:q!` | 强制退出，丢弃修改 |
| 通用 | `:set nu` | 显示行号 |
| 通用 | `:set paste` | 粘贴模式（防止粘贴时缩进乱掉） |
| 通用 | `:%s/old/new/g` | 全文替换 |
