## 第一章：Windows 系统与 VS Code

### Windows 系统

| 快捷键 | 作用 |
|---|---|
| `Win + E` | 打开文件资源管理器 |
| `Win + D` | 显示/隐藏桌面 |
| `Alt + Tab` | 切换窗口 |
| `Win + Shift + S` | 区域截图 |
| `Ctrl + Shift + Esc` | 打开任务管理器 |
| `Win + L` | 锁定电脑 |
| `Ctrl + C` / `X` / `V` / `Z` | 复制 / 剪切 / 粘贴 / 撤销 |
| `Win + V` | 剪贴板历史 |

### VS Code

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Shift + P` | 命令面板 |
| `Ctrl + P` | 快速打开文件 |
| `` Ctrl + ` `` | 集成终端 |
| `Ctrl + Shift + V` / `Ctrl + K V` | Markdown 预览 / 并排预览 |
| `Ctrl + B` | 侧边栏 |
| `Ctrl + /` | 注释/取消注释 |
| `Alt + 点击` | 多光标 |
| `F2` | 重命名符号 |

## 第六章：Vim（选修）

### 模式切换与普通模式

| 快捷键 | 作用 |
|---|---|
| `Esc` | 回到普通模式（迷路时先按它） |
| `i` / `a` / `o` | 进入插入模式：光标前 / 光标后 / 下一行 |
| `:` | 进入命令行模式 |
| `v` / `V` | 可视模式 / 可视行模式 |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右移动光标 |
| `gg` / `G` | 跳到文件开头 / 末尾 |
| `0` / `$` | 行首 / 行尾 |
| `/word` / `n` | 向下查找 / 下一个匹配 |
| `x` / `dd` | 删除字符 / 删除整行 |
| `yy` / `p` | 复制整行 / 粘贴 |
| `u` / `Ctrl + r` | 撤销 / 重做 |
| `.` | 重复上一次操作 |
| `dw` / `ci"` | 删除一个单词 / 修改引号内的内容 |

### 命令行模式（保存与设置）

| 命令 | 作用 |
|---|---|
| `:w` / `:q` | 保存 / 退出 |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | 强制退出，丢弃修改 |
| `:set nu` | 显示行号 |
| `:set paste` | 粘贴模式（防止粘贴时缩进乱掉） |
| `:%s/old/new/g` | 全文替换 |
